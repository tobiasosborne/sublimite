# edit-11v worker report

Implemented the active-buffer snapshot request lease, viewport query publication,
per-cell syntax foreground paint, default-language extension dispatch and linked
opt-ins. New buffers start plain; stale colours remain until a complete current
query batch lands. Full-document completion refines viewport context. Minimap
syntax colour is outside scope. Design choices: docs/decisions/edit-11v.md.
No bd or git commands ran. No protected handoff/worklog/planning files changed.
