# P1.9f — journal review fix (edit-4w1.45)

## File review §6 — externally writable retained hard links

**Verdict: valid BLOCKER, fixed.** External descriptors and hard-link aliases
can modify the retained inode after replacement, invalidating recovery.

**Fix:** create a private sibling inode via FICLONE or a WORK_BULK copy with
a 64 KiB buffer (E: scratch bound). Validate source identity and before/after
size/mtime/ctime/path; check the snapshot's size/prefix CRC and distinct inode.
Sync its data and directory before publishing PREPARED. Matching BASE records
use its freshly captured identity; the SAVE marker keeps the original target
identity/cutoff. The owner drains its router while waiting. A write seam selects
copying for deterministic fault tests. Remove incomplete snapshots before
publication; retain complete ones on ambiguous checkpoint failure. Copying
requires space for the previous file; failure prevents save authorization.

P1.9d's transaction/retry/retirement order, P1.9e's FULL/bounds/path semantics,
and fsync defaults remain intact. No other module or frozen header change is
needed; journal.h changes only comments. Cadence remains edit-4w1.34.
