# P2.5c — raster review harness fixes (edit-e6x.23)

Scope: review P2.5-1 §§9–14, 16, 18. All accepted. Only the benchmark,
existing raster comparison/allocation sections, and raster STATUS are changed;
render_test.c, backend implementations, frozen headers, and the file-end area
reserved for P2.5b are preserved. Self-checks use synthetic samples; they are
correctness tests, not performance measurements. The first self-check revision
retained the existing verdict policy and produced the red lines below before
implementation. No performance benchmark was run to obtain those reds.

## §9 — incomplete G3 operation

Accepted. Ingress now precedes mutation, frame begin, damage marking and strip
construction. A null-backed self-check records ingress and first mutation to
prove their order. Warm rows are explicitly `subset_TRACK`, never G3 PASS.
A gate-mode subset over budget fails; a subset within budget cannot establish
acceptance. Actual minimap integration requires the owning integration bead;
do not substitute the old 0.26 ms (E) allowance for actual work. Proposal:
include minimap content generation, damage, raster and upload in the ingress-to-T5
frame before enabling G3 acceptance. No header change made.

Red: `SELF-CHECK section=9 FAIL`
Green: `SELF-CHECK section=9 PASS`

## §10 — dropped/error/invalid/incomplete G3z

Accepted. Prime one baseline then count 10,000 intervals (gate requirement).
Keep accumulated misses across later skipped pixmaps; non-pixmap/skip completion,
nonadvancing/zero MSC, frame/diagnostic errors and incomplete gate runs fail.
Quick scrolls say `scroll_300_TRACK`, not scroll_10k. Synthetic cadence tests
exercise errors, incomplete runs and a miss followed by a dropped frame.
On Xvfb, MSC gaps are diagnostic TRACK counts, not physical missed refreshes;
data errors still fail TRACK. All real G3z rows explicitly SKIP and gate mode
returns 2 (not measured): the current public diagnostics cannot establish a real
vblank source/rate. Proposal for the backend owner: expose verified display/vblank
capability and actual refresh rate, then enable the physical row only with that
fixture. This bead changes no raster/render header or backend.

Red: `SELF-CHECK section=10 FAIL`
Green: `SELF-CHECK section=10 PASS`; `SELF-CHECK section=10-history PASS`.

`POLICY section=10 case=miss_then_drop rc=0 gate_failure=1 expected=1 PASS`;

## §11 — ineffective G3i limits

Accepted. Gate-mode idle budget checks use A 8 ms / floor(1e9/90) ns (G),
B 10 ms / floor(1e9/60) ns (G), and propagate reporting failure. Normal idle
wait is at least 15 s; shorter quick waits are explicitly TRACK, with the actual
idle duration in the name. Bulk jobs stop before the isolated idle sample.
A synthetic 100 ms sample fails a gate budget and passes only the short-idle
TRACK check. Missing minimap still makes complete G3i acceptance unmeasured.

Red: `SELF-CHECK section=11 FAIL`
Green: `SELF-CHECK section=11 PASS`; `SELF-CHECK section=11-short-idle PASS`

## §12 — contention and target B

Accepted; standalone cases added, integrated acceptance remains unmeasured.
Default matrix covers A 2880×1800 and B 1920×1080, both atlas sizes, idle,
active index scan, active find scan, active save copy, and all three queued with
one active/two queued. Preallocated memory workloads poll cancellation after
64 KiB chunks; setup requires actual worker progress and verifies queue depth.
The self-check starts/stops every fixture as well as checking B dimensions and
G3 4/5 ms, G3i 10/T ms limits (G). Warm, typing, scroll, error and reporting
failures propagate. Surrogates are explicitly named `synthetic_*_TRACK`; these
are memory/queue contention guards, not actual index/find/durable-save evidence.
B resolution on this X11 host is explicitly a proxy for the Windows B fixture.
Proposal for the owning integration bead: invoke the real three module jobs with
real corpus snapshots/I/O, then repeat the matrix on the actual B fixture.
Changing another module to achieve that was outside this bead's authorization.

Red: `SELF-CHECK section=12 FAIL`
Green: `SELF-CHECK section=12 PASS`

## §13 — vacuous partial-image comparison

Accepted. The regression first required the final partial edit to differ from
its initial colour: the old ten XORs failed. Replace them with distinct edits;
compare the full window with a fresh scalar image after the initial full frame
and every partial frame. Alternate disconnected rows 0/2/5 and adjacent rows
2/3, crossing job partitions; every unchanged row is also compared. Null or
short readback fails. A negative control suppresses partial ShmPutImage uploads;
the revised test detects stale pixels on the first partial image.

Red: `raster_test:287: FAIL cells[8].fg != initial_fg`
Green: `raster pixels: PASS full + 10 individual partial comparisons (disconnected/boundaries/unchanged rows)`
Negative control: `raster_test: 2952 window pixels differ`, exit 1.

## §14 — disabled external allocation assertion

Accepted. Remove the false guard-active replacement. Driver-local wrappers leave
the frozen suite unchanged, start a guard at each frame begin, end it immediately
when submit returns, accumulate counts and require exactly 10,000 windows. Each
nonzero count fails immediately; present/completion allocations are excluded per
P2.0's settled law-2 addendum. The conformance window is now mapped. The short
mapped lifecycle/pixel test remains independent. Late-allocation injection at
frame 1000 proves the long-loop assertion is active.

The exhaustive loop still drives the real CPU backend and real X completions;
it is not a deterministic completion fixture. There is no public hook to replace
CPU fence/Present transport without faking hardware acknowledgement or editing
src/raster. Proposal for the backend owner: inject a deterministic server/fence
transport for the exhaustive lifecycle/allocation test, while keeping the short
mapped real-X test as display evidence. Do not replace CPU submissions with null
backend submissions or signal synthetic completions into a live CPU backend.

Red: `raster_test:314: FAIL !edit_malloc_guard_active() || external_guard_enabled()`
Green: `raster law2: windows=10000 allocations=0 guard=1 scope=input->submit`
Late-allocation negative control: `raster law2: FAIL frame=1000 allocations=1 scope=input->submit`, exit 1.

## §16 — missing display accepted as success

Accepted. Missing/empty DISPLAY or failed display initialization reports explicit
SKIP/not-measured. Gate mode returns 2; explicit TRACK may skip the missing fixture
with 0. Errors return 1. Missing minimap, real bulk integration, B fixture and
verified vblank likewise cannot yield complete acceptance, even with DISPLAY.

Red: `RED section=16 expected=2 actual=0` (`env -u DISPLAY ...`)
Green: `gate missing-display exit=2 (expected 2)`;
`TRACK missing-display exit=0 (expected 0)`; `SELF-CHECK section=16 PASS`.

## §18 — exact T/2

Accepted. G3's A p99 integer limit is floor(1e9/(2×90)) ns (G). An integer
nanosecond sample passes exactly when it is at or below the rational bound.
The boundary self-check accepts 5,555,555 ns and rejects 5,555,556 ns and
5,558,000 ns; these are synthetic test values, not measurements. Idle T bounds
are derived similarly for both targets.

Red: `SELF-CHECK section=18 FAIL`
Green: `SELF-CHECK section=18 PASS`
