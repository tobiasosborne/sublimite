# edit-2j9 — benchmark and fuzzer decisions

Keep the minimum qualified population at n >= 10000 (G), repeating the entire
binding operation. Optional probes preserve workload size and refuse population
certification. Small/cached workloads have distinct regression names/budgets.

Extend a private copy of the supplied log with its own prefix to reach line
10^7 (G), preserving the source's line width and increasing source work. Never
shrink the requested seek. Map anew and reset the index for every binding sample.
Verify cold source nonresidency after evicting only private fixture data.

Findui word-pair setup prepares a full file once, then uses new mappings for each
request. Savectl uses a private immutable file-backed source independently of
its atomically replaced destination; full-content checks happen outside timers.

Share editor per-key correlation and structural verdicts in a bench header.
Enable journaling for large typing rows so the shared mutation/journal invariant
is meaningful. Repeat real-cadence idle sessions; due-now blinks are regression
observations only. TRACK suppresses timing certification, not structural errors.

Do not claim unavailable endpoints: snapshot/enqueue does not certify a shown
saving frame; a cached editor mapping does not certify new-mapping G6; null
completion does not certify displayed cadence or authenticated all-thread wakes.

Use isolated save fixture processes plus local monotonic phase timers. Deadline
failure terminates the process without freeing arguments still borrowed by work
or joining an unresponsive worker. Bound the reap phase too. Normalize supervisor
structural error codes locally; do not change the shared verdict utility ABI.

Keep controlled historical-outcome injection macros in the fuzzers to demonstrate
that the new assertions reject the old literal-limit and reused-slot failures.
Only benchmark/test/fuzz infrastructure and one scroll comparison are changed.
