# edit-3620: Keep reports an unexaminable target instead of dismissing

## Cause
In the Keep branch of `editor_check_sources` (src/editor/buffers.c), the
target rebase was guarded by `file_id_stat_path(b->save_path, ...) == FILE_OK
&& savectl_rebase_kept_target(...)`: a stat error (FILE_ERR_IO: EACCES, EIO,
ELOOP; absence is FILE_OK with `exists = 0` and is rebased normally) skipped
the rebase *and* the early return, so Keep fell through, cleared the prompt
and the rebound OPEN_FAILED marker, and left the save controller on its
pre-rename baseline. The next Ctrl+S then failed as "source changed" with no
prompt having said anything.

Reachable deterministically for a Save As (target_rebound) COPY buffer with
no journal: there `file_resolve_keep` and `journal_capture_base` are skipped,
so this stat is the first one Keep makes. Otherwise it is the window between
the earlier stats and this one.

## Fix
Stat failure is treated like a refused rebase: retain the prompt. Both now
also set a recovery notice, `Keep failed: R reload / K keep`, because the
save overlay draws the notice over the prompt row, so the notice repeats the
choices. The notice is cleared when a later Keep succeeds or Reload is
chosen (identity check against the static string, the checkpoint.c
busy_notice pattern), and by the first mutation as for every notice.

## Choices
- The refused-rebase path (ut0m) gets the same notice: it is the same
  "Keep could not reconcile the target" state, and silent retention was the
  only other non-reporting exit of this block. The earlier silent returns
  (file_resolve_keep refusal, BASE capture/checkpoint refusal) are unchanged.
- No new allocation; Keep is off the typing path (explicit choice in
  maintenance).

## Test
`tests/editor_session_test.c:kept_target_unreadable` (`--edit-3620`): Save As
into `target/saved`, edit, external rename-over, wait for the prompt,
`chmod 0` the parent (search denied, so lstat returns EACCES), Keep. Asserts
the prompt stays and the notice is set; then restores 0700, Keeps again
(rebases, notice cleared) and saves `xbase`. Skipped as root (search
permission is bypassed).
