## 6. Decisions and alternatives

Use EGL XCB native connection/window pointer forms and the platform's exact
native visual; load libEGL/libGL only in worker init, never link them. Require
GL 3.3 core and GLSL 330. Missing libraries/symbols/context/extensions or genuine
matching Present support return INIT/UNSUPPORTED with cleanup for CPU fallback.
Mesa-only startup probing verifies three actual swaps' low-32-bit SBC serial
sequence and nonzero PIXMAP MSC; this is an observed convention, not a portable
EGL guarantee. A private Present selection verifies kind/serial/window/MSC before
accepting the frozen platform callback, which lacks kind/mode. NotifyMSC and
synthetic timers were rejected as substitutes for displayed-frame completion.

Reserve CPU instances, strips, packed R8 atlas cache, page offsets, glyph-seen
flags and texture-row dirty flags in init arenas. Submit reads dirty cells and
referenced glyph rectangles, copies pixels into that cache, and bakes metadata
into instances. No caller cell/strip/glyph/page descriptor pointer survives.
Atlas upload now belongs to present: coalesce dirty texture rows and upload
from owned cache. This adds one byte per reserved texture row. Deferring borrowed
caller atlas pointers was rejected because snapshot ownership already has a
stronger consumed-before-return implementation and is easy to verify.

`EDIT_GL_VBO=orphan|persistent` remains init-only; default orphan. Persistent
requires ARB_buffer_storage/coherent mapping and otherwise reports orphan
fallback. Submit writes the persistent mapped memory without native calls;
orphaning/BufferSubData occur in present. T5/T6 queue-one protects reuse.
`EDIT_GL_SWAP_INTERVAL=0|1`, default 0; scroll uses a separately initialized
interval-1 backend. EGL context detach/release occurs before worker init returns;
first native bind happens in UI present. This removes first-submit native lazy
allocation/round-trip risks. Presentation and event polling remain UI-owned.

Use one instanced quad per damaged cell, scissor and one draw per strip; exact
integer coverage blend `(fg*a + bg*(255-a) + 127)/255`, inverse and underline.
Keep an RGBA8 framebuffer, update strips there, then blit before swap to preserve
undamaged pixels independent of native buffer age. The full blit is included in
T5, including on typing rows. Implicit backbuffer retention was rejected.

After successful eglSwapBuffers, issue glFenceSync/flush; event performs one
zero-timeout glClientWaitSync poll, never a blocking fence wait on UI. Common
adapter records T4 and dispatches default src/trace T5/T6 once with original
frame IDs. Bench timing hooks also explicitly forward to those trace helpers.
T6 comes through plat on_present_complete and private PIXMAP verification;
MSC is the actual completed swap's displayed MSC. Timestamps are correlated
CLOCK_MONOTONIC observation times, not raw X UST. Shutdown may quiescently finish.

Keep RTLD_NODELETE for EGL/GL process-lifetime vendor/display cache roots while
closing acquired loader handles and destroying context/surface/GL/Present/arena
resources. Predecessor evidence showed an EGL/GLVND cache LeakSanitizer report
when unloading. Current Xvfb sanitizer runs keep leak checking enabled.
