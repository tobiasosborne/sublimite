## F1 decision record

| Claim | Verdict and check |
|---|---|
| (a) UI-only source, no font device pins | **Yes for published source tiles.** A font worker can compose in exclusively assigned unpublished storage and hands it over on settlement. The UI alone reads the published tile to make a packet. After accept, overwrite/reassign the UI source while delaying the raster worker or GL upload: the packet still contains the original bytes. Delete pin_begin/image/abort/commit/retire and the font (owner, token, epoch, frame) ledger. Keep CPU publication protection, including a live candidate across MORE, and physical worker retirement. An epoch and frame ID still authenticate backend events. |
| (b) Glyph work proportional to newly sent tiles | **Yes for UI tile transport in steady state.** Settlement or reassignment queues a slot once. Submit takes a FIFO prefix. An ASCII edit using resident art visits zero runtime tile records and copies zero R8 bytes even when every other visible cell uses a different glyph. Checking/copying changed cells is separate. A newly ready glyph with many pending users can cause substantial repaint, and recomposition of font-QUEUED users has its own producer cost. The claim would be false for total UI paint or total backend work. |
| (c) Recovery from UI tiles | **Yes for the current generation.** A packet accepted just before a partial upload may be lost. Quiesce that epoch, invalidate every delivery credit, install the current sheet, submit a full current picture and resend live INK from the source in bounded batches. A tile evicted in the meantime has no valid current CPU reader. Recover its current replacement if any. Discarded presentation with an intact device needs no atlas replay. |
| (d) A second copy of S tiles | **Yes for persistent runtime texels of one active backend**, S slots × T tight bytes before texture alignment. RAM on XShm, texture storage on GL. Peak also includes the immutable sheet, versions/descriptors, retained cells, draw targets, a packet of up to B tile bytes, and any overlapping setup banks/backends actually admitted. GL has no mandatory full CPU shadow of the device atlas. |

A borrowed-page frame fails the delayed-worker overwrite above. Repacking every referenced image avoids that race but visits unchanged cells/images. A slot number alone also fails: delay delivery of slot s's replacement while its previous black glyph remains in the texture. The next white-background cell must not draw that glyph. The version check below is necessary even with depth one.

## Structures and invariants

| Structure | Single invariant |
|---|---|
| Surface binding | A surface incarnation and geometry serial identify one logical-to-physical mapping including client pixels, fixed regions, scale and admitted font metrics. |
| Producer view | One key (buffer incarnation, text serial, geometry serial, layout owner/publication) identifies the cells, hit intervals, affinity and viewport transform used together. |
| render_cell | Its 20 pointer-free bytes describe one settled cell footprint and the precise image identity it may sample. |
| UI tile directory | For each runtime slot in a generation, only its current settled INK version has published readable R8 bytes. |
| Delivery queue | For a bound epoch, every current exportable replacement still owing delivery occurs once in the pending FIFO or in its provisional prefix. |
| Preparation cursor | Every saved offset names private staging or a position in a re-acquirable, serial-checked source. |
| Frame packet | One accepted (epoch, frame) owns all variable data needed to apply its patch to the preceding accepted backing. |
| Retained backend scene | Its cells, layer geometry and atlas reflect an ordered prefix of accepted packets before any draw that samples them. |
| Retirement record | A live accepted identity owns the sole flight slot through both real device completion and a terminal presentation result, or through quiescence on loss. |
| Worker argument | Its storage survives the physical end of its work lease, including cancelled or mailbox-parked continuations. |

### Cell, tile and ownership boundary

Keep the pin's field widths/order: u32 glyph_index, atlas_slot, fg, bg and u16 attrs, reserved (P, four words plus two halfwords = 20 bytes). Within a bound atlas generation use glyph_index as the nonzero **image version** of atlas_slot. Allocate disjoint stable indices for ASCII/settled marker art and S runtime tiles. A slot version changes on each new image and never aliases an older image in that generation. Exhaustion requires a new generation/full bind. Clear the version directory on rebind or use generation-qualified tags. A baked sheet is uploaded at setup before first use, including a valid settled marker for each span. ASCII singleton lookup is direct. A composed cluster carries its own span and image. The producer preserves original bytes, width and presentation under A16.

Zero identity with NO_SLOT is a valid inkless cell. This covers EMPTY, spaces and a key still awaiting font composition. F7 pending art is background-only at the final advance. Settled MISSING, LIMITED or PRESSURE uses the valid marker. An **already composed** tile awaiting transport can retain its logical (slot, version) in the cell. The backend draws its glyph only if its installed version matches. A mismatch emits zero ink with the same backgrounds, selection, underline, wide pair, hits and advance. This distinguishes a valid owed version from malformed producer input. Validate a changed ink cell against the current UI directory or sheet before accepting it. Reject a fabricated or stale identity. Wide left/right are adjacent in one row, with matching colors/non-width attrs and no second glyph on the right. Reject clipped orphan halves, nonzero reserved fields, unknown attributes and non-opaque RGB encodings.

Ordinary dirty patches may omit only unchanged, previously validated source rows under the same binding. Compose from complete layout row slots, add independent chrome, selection/caret and overscan, and compute damage against the **last accepted** composition. Carry producer change marks across refusals, coalescing by union, or force full on unknown ancestry. A dirty span covers whole wide pairs. Full-width row patches make validation local. No API accepts a mutable full grid plus a caller's claim that its unexamined cells are valid. Unsubmitted rows have no representation in a patch. First frame, rebind, resize, tab change and invalid retained backing require full initialization. Present/expose must restore the whole affected surface. Full initialization writes the enabled overscan and all visible layers, including fractional-cell margins.

### Delivery and admission

1. Settlement publishes at a UI boundary. On publication insert the slot at FIFO tail if absent. On reassignment replace its queued version in place. Retire vacant/EMPTY slots from this queue. CPU view holds or equivalent publication protection prevent source reuse underneath a current view. Superseded cells in a backend retain their own sampled bytes until their admitted patch/replacement. The renderer has no path back to font jobs. A settlement of previously NO_SLOT users requests a new producer paint serial, including chrome and overscan. The revised layout contract permits reuse of geometry/hits for this repaint.
2. A synchronous BUSY check precedes staging. Pick an ordered prefix of complete current tiles fitting both the byte and descriptor caps. Keep its nodes reserved at the head until accept. A transport-only frame can drain them without input. Wake on retirement while pending. After a finite set of settlements, fair scheduling and successful presents drain the queue. For a stable backlog of n equal tiles with k slots of grant per accepted packet this takes at most ceil(n/k) packets (P, k ≥ 1). Continuous reassignment can supersede a specific obsolete version.
3. Check dimensions and arithmetic before dereference. A tile source identifies slot, version, valid ink width/height, page dimensions, stride, length and top-left rectangle. Validate nonzero extents within cell span, stride ≥ page width, rectangle inside page and last addressed byte within length with checked add/mul. The destination is a fixed double-cell R8 tile; store actual extents with it, tightly pack its sampled rows and define uncovered texels as zero (clip reads to extents). Sum tight w×h lengths, check distinct slot count, destination extent and each byte offset. Byte cap may leave later valid tiles pending. Invalid metadata for a selected tile rejects the attempt. A legal largest tile must fit by itself or geometry admission fails. No padded bytes travel. Copy once on UI into the packet. Backend uses the same offsets, with GL upload row orientation and unpack alignment explicit.
4. Staging is resumable. Reacquire source rows, tile and region views for each bounded copy step, verify composition/binding/selected-source versions, and retain only offsets between UI turns. Freeze the selected delivery prefix logically during the attempt. A mutation affecting the prefix cancels the attempt **before** mutation and leaves current obligations queued. Later unrelated settlements may append. A superseding edit, geometry change or incompatible paint abandons staged bytes. Retain the old accepted picture until its successor is complete. All prep, including copying a large row or region, can stop mid-row.
5. In the non-reentrant accept step, recheck candidate identity, damage base, epoch and source validity tokens. All fallible work, storage reservation and bounds checks precede publication. Commit the prefix by unlinking it as a batch, accept the packet by release/acquire handoff and publish the actual input association and layout/top together. Validation of these serials is O(1); no per-cell cleanup or O(S) bitmap clear at commit. Use an intrusive FIFO with one node per slot and an increasing enqueue number. A node belongs to the queue iff linked in this epoch and its number exceeds the accepted watermark. Accept advances head and watermark to exclude the selected prefix and fixes the new head/tail links. Reassignment of a still-linked node preserves its ordinal. Eviction unlinks in O(1). Aborting never advances the watermark. Retire the epoch before ordinal exhaustion. A refusal consumes neither ID, input association, atlas credit nor damage. No backend operation can turn an already accepted packet into a synchronous refusal.
6. The backend updates texels, extents and installed versions before drawing any cell in the packet. Update the retained cell patches and redraw every destination whose sampled source changed, including unchanged logical cells waiting for a delivered tile. A simple correct backend may invalidate the whole text and chrome on tile installation, recompose fixed layers and reuse retained cells, at O(physical pixels) draw cost. For the typing path keep a backend-owned list of referencing cell indices per runtime slot, linked from retained glyph-bearing cells. Remove old/add new references as patches land. On installation, mark the old and new footprint of users including adjacent Q8 output rows, wide halves, overscan and covered layers. Bound fan-out by the number of retained cells. No reverse index of borrowed layout rows is needed on the UI. Failure after a partial backend update is LOST. Never issue the next patch against an uncertain base.

For LOST/restart rescan the UI directory with a cursor, O(S) once per epoch and bounded per UI step, while enqueueing new settlements normally. Tag queue membership by epoch, deduplicate, and ignore inactive/superseded entries. Rescan requires no R8 re-composition of held INK. On metric/face change activate one admitted sheet/runtime generation for the entire new picture. Complete or quiesce the old flight first. Failure leaves the last viable admitted binding in service or reports surface/backend unavailability. Reserve transient old + new resources when using the font proposal's two banks. Only CPU holds/jobs delay retirement of the old font bank after its final UI read.

## Surface, damage and sampling

**Q3.** Qualify every frame and coordinate-bearing input by coherent geometry serial. Scale-only changes count. Collapse adjacent unused configure snapshots only while no dependent input, candidate commit or accepted frame intervenes. Handle the atomic key in ingress order with its inline UTF-8. A pointer uses the accepted layout serial and saved transform matching its event geometry. If stale, leave the selection alone. Never relabel input or an in-flight frame with a newer surface. Resize/rebind at idle after successful common-cap admission. Only a READY layout publication may carry the edit into G1. During MORE/BUSY preserve the previous picture and hit binding. Revalidate layout_present’s owner/serial preconditions before the handoff. Within that same non-reentrant UI step, call it with the exact accepted candidate. The commit has no remaining fallible lookup. Presentation feedback measures display separately.

**Q4.** Store canonical sorted, disjoint, nonempty, maximal adjacent dirty-row runs; zero runs is valid. Check start/count, addition and row range before loading any cells. Full has one full-height run for a nonempty grid. Keep scroll source row damage separate from visible output runs. Region damage is independent: top-left opaque RGB32, physical position and checked element stride/length. On move, resize, removal or layer-order change damage both old and new extents, restore underlying content, reapply fixed overlay. Region-only, caret-only, margin-only, tile-only and zero-damage packets are legal. Keep pixel coordinates and layer clips in the packet. A full packet includes all enabled fixed pixels. Rejected input yields a reason and preserves the candidate for correction at its producer.

**Q5.** Clip to the physical client. Fill margins with surface background. Text is sampled in text-clip-local coordinates; fixed gutter/chrome/region use unshifted surface coordinates. Use the same transform in clip and wrap, including at the bottom. For a destination text scanline y, let q = −origin_y_q8, 0 ≤ q < 256H for cell height H. Read fully resolved RGB scanline y + floor(q/256) and, only if f = q mod 256 is nonzero, its successor. Map the latter through the text source directory to the extra row even when a fixed status row follows the clip. Keep EOF padding valid. Decode 0x00RRGGBB, apply inverse after producer-resolved selection/cursor styling. Resolve glyph coverage a in R8 per channel as floor((fg·a + bg·(255−a) + 127)/255), underline on the final local scanline. Across the two resolved samples output floor(((256−f)·c0 + f·c1 + 128)/256). These are integer RGB code values (P, R8 and Q8 denominators). Disable filtering, implicit sRGB conversion, dithering or blending that changes readback. For GL, resolve the unshifted text and overscan to a retained integer RGB(A) surface using the direct-cell/TBO draw. A scissored composition pass fetches the two resolved scanlines with integer texelFetch and applies the same channel expression. Reserve this extra source surface at its actual format/pitch, including overscan. This allows the second sample to have different colors, underline or wide-cell ownership from the first. Clip fixed layers last. Expand source damage through the inverse sampling footprint rounded outward; an origin/clip change damages the union of old and new destinations. A shader translating quads then truncating texel coordinates fails at f=128 across black and white (expected 128, P).

**Q6.** One off-UI presentation owner holds the raster X connection, XShm pixmap/fences, native serial matching and teardown. It consumes immutable accepted commands. Parallel kernel jobs touch disjoint pixel output and the installed read-only scene only after atlas apply. Present complete rows only. Every X request capable of reading, including a margin flush, cursor upload, region upload and idle/fence query, belongs to that owner. UI submit reaches only prepaid memory and a bounded wake handoff. A private connection driven on UI still permits the attributed allocation. Forward typed acknowledgments to the common frame FSM.

**Q7.** GL uses one core 3.3 direct-cell path with a glyph metadata TBO and a private texture. Warm off-path, without swapping a diagnostic frame onto the visible window. Transfer exclusive context ownership before use. Keep driver calls out of guarded UI prep. SUBDATA to preallocated buffers is the baseline candidate. Compare ORPHAN with identical final contents, accounting for rebuilding retained data after orphaning. Measure PERSISTENT only on a device reporting buffer storage. A path requiring that extension cannot be the sole winner. Record ingress→T4, T5, matched presentations, readback, release allocations and after-idle tails on X11 and Wayland under the same workload. Freeze the frame ABI here; the upload winner requires that experiment. X11 init failure may select XShm at a new binding. Wayland EGL failure is explicit.

## Frame lifecycle and owners (Q8/Q9)

| State or event | Owner, action and exit |
|---|---|
| CLOSED → OPENING → IDLE_FULL | Off-path owner provisions common caps, sheet, packet and backend private storage. UI adopts successful initialization once. Roll back partially initialized native and arena resources on failure. IDLE_FULL accepts only a full coherent base. |
| IDLE_FULL / IDLE → PREPARING | UI borrows current sources. MORE parks its cursor. BUSY on active flight has no side effects. Abort/stale/invalid/capacity returns to the same idle requirement with damage and delivery obligations intact. A suspended/minimized empty surface waits for a drawable binding. |
| PREPARING → ACCEPTED | UI assigns a nonzero monotonically increasing ID within a nonreused backend epoch. Records final input sequence (or no new input for a repair), view and surface IDs. Backend owns the immutable slot. Caller can overwrite cells, metadata, tile bytes and RGB after the handoff subject to its own CPU readers. |
| ACCEPTED → ISSUED | Backend applies packet, draws and issues actual present once. Busy native readiness preserves the slot. T4 is successful native present submission for this ID. Keep any authenticated early signals private until T4 is known; failure before issue is LOST. |
| ISSUED, device axis | WAIT_FENCE → DEVICE_DONE exactly once on actual device completion. Publish T5 at max(T4, correlated fence timestamp). Raster-work completion and XShm source reuse alone do not discharge this obligation. |
| ISSUED, presentation axis | WAIT_DISPLAY → PRESENTED or DISCARDED exactly once. PRESENTED publishes matched-clock T6 for the original frame (clamp early observation to T4); DISCARDED retires display untimed. A frame callback only schedules work. Device and display can finish in either order. |
| Both axes terminal → IDLE | Backend releases/reuses flight storage only after its physical jobs also end. UI may then feed the coalesced next candidate. Retained backing and atlas survive ordinary discard. A later displayed frame must include the complete current scene even if native swap buffers have undefined age: present the retained full result or restore native damage against a known buffer history. |
| LOST or close → QUIESCING | UI stops admission, invalidates old attempt/epoch, requests cancellation. Backend stops sampling and quiesces GPU/server access, unregisters sources, drains stale messages and confirms all physical leases before releasing resources. No synthetic T5 or T6. Close → CLOSED. Restart → OPENING with fresh epoch, empty delivery credit and IDLE_FULL. |

Use exhaustive enums for lifecycle and both independent axes. Buffer early evidence by identity as typed axis values; repeated/foreign events do nothing. Match X11 Present PIXMAP, window, request serial and valid displayed mode/MSC; distinguish skipped presents. Wayland requires the matching swap feedback object, result and correlated monotonic clock. Report timing unavailable if a real display has no convertible timestamp; a callback timestamp cannot substitute. Keep synthetic null timing labeled. Frame-ID exhaustion forces a quiescent epoch change before reuse, and native cookies may never alias a live observer. A mailbox wake, refresh callback, late old fence or close event cannot free a new flight.

At worker mailbox fullness retain the typed result and current phase in the leased argument. Call work_continue after refused work_publish and return. The continuation parks until drain frees space. Retry publication without redoing upload, fence or present. Poll work_should_stop within the landed 5 ms CPU bound (G, work.h). Keep pumping the pool even for stale results, recheck work_handle_finished after each wake and before freeing any job argument. Physical completion can occur without a message. Native waits need cancellable wake/disconnect and bounded loss handling. A hung native wait never authorizes memory reuse on a UI deadline.

## Capacity and time bounds

P denotes structural derivation, G a gate, M a cited measurement and E a planning estimate. Identifiers, field widths and protocol versions refer to the named contracts. Let R be visible composed grid rows, C their width, e ∈ {0,1} the extra text source row, V = C(R+e). The extra row may use fewer columns but reserve C. W,H are physical cell pixels, T = 2WH is the largest packed double-cell R8 tile. S counts runtime slots, A immutable sheet entries, Z changed source cells including changed overscan, J changed row runs, U changed RGB region pixels, N selected tile records and L their total tight payload. All arithmetic below is checked before narrowing or allocation.

| Operation | Bound and derivation |
|---|---|
| Cold admission (P) | Intersect platform/implementation limits for physical client extent (including partial cells), grid V, signed native destinations, W,H, texture tiles/layers, TBO texels/bytes, row pitch and GL integer/address ranges, XShm segment/stride/pixel format, framebuffer and region dimensions. Reserve 20V packet cell bytes, ceil(R/2) run records (alternating dirty rows), separate overscan, up to 4Umax region bytes plus tile and descriptor caps. Size retained scene and backend resources separately. Check surface multiplication using actual stride. Reject incompatible baseline limits with required vs available values before adoption, even on GL-only runs of the parity suite. |
| Sparse prep (P) | From producer change records build a row damage bitset. Iterating its words costs O(ceil(R/word_bits)+J), or use already canonical runs. Validate/copy exactly Z cells once, O(Z) identity/pair checks plus O(1) carried boundary state across grants. Total UI work O(ceil(R/word_bits)+J+Z+U+N+L) including row copies. The tile queue takes at most N+1 head/candidate inspections when it stops at the first tile that will not fit. Membership updates cost O(1) per source change. Stable atlas with empty damage needs no cell/slot validation walk. |
| Sparse vs full bytes (P) | UI→packet payload = 20Z + 4U + L plus O(J+N) records and fixed geometry. L ≤ min(B,NT); N ≤ min(S, descriptor cap). A dirty full-width typing row without scrolling costs 20C bytes, a region-only frame costs 4U with a settled atlas, a full physical update up to 20V + 4Umax + B. At the pin's largest cited layout fixture, 360×300 plus overscan gives 108,360 cells, 2,167,200 bytes full vs 7,200 bytes for one row. Actual admission follows prepaid dimensions. |
| Backend apply and redraw (P) | Install L bytes and N extents/versions, patch Z cells and U pixels. Per-slot cell lists require O(V+S) indices. Let F be total users of this packet's replaced slots, F ≤ V because each cell names at most one slot and each slot occurs at most once. Damage marking is O(Z+F+U) including a constant number of adjacent output rows per changed source row. Whole-width row raster may still shade every pixel of the physical client. GL rendering/full-surface presentation and server copy can also cost a physical frame. These stages count if before T4. |
| Peak storage (P) | Runtime R8 = ST on UI and ST at the backend, plus B packet bytes and O(S+Nmax) tags/nodes/records. Add A·W·H sheet pixels for single-cell entries and separate marker extents as needed on each side, row padding/texture rounding, O(V) retained cell/reference data, packet capacity above and physical target(s) at actual pitches. Include source holds, job arguments and simultaneous old/new setup banks in peak admission. At W=10,H=20 from the font send-back, a full tile is 400 bytes and the extra backend runtime payload is 400S bytes. |
| Recovery (P) | Directory replay costs O(S) inspections once per restart, at most ST tight bytes for the stable live runtime set, across accepted capped frames. First frame also restores sheet and full backing. No O(S) scan is charged to an ordinary edit. Cancelled candidate cost is the prefix actually examined/copied; count it in the key's latency if that key waits for it. |

**Size the grant from time and storage.** G1 is T4−T0 for the frame containing the edit, 1.0 ms p50 / 2 ms p99, and each UI slice including callbacks is ≤0.5 ms wall time with an input check between slices (G, perf §0.2). Packet acceptance is a useful intermediate timestamp. Stopping the clock there would exclude raster/driver queueing or depth-one backpressure. Also record the earliest ingress represented when edits coalesce. Never count a stale retained picture or a previous frame's T4.

For an initial cap, measure resident strided gather + descriptor validation on the target over the admitted shapes. Let t be a conservative measured time per largest tile including row/descriptor overhead, h other work in the slice, and k_store the lesser of descriptor capacity and floor(prepaid payload/T). For ordinary one-slice prep choose k ≤ min(k_store, floor((500,000 ns−h)/t)) when positive and set B=kT (P formula on G/M inputs). Clamp to S. Control record count independently so tiny rectangles cannot consume unbounded metadata work. If the residual grant is zero on a busy key, give priority to its cell patch and schedule tile-only repair with a positive grant at the next opportunity. Geometry admission requires storage for one entire maximum tile. When time per tile exceeds a slice, select at least one on a repair attempt, copy in bounded row fragments across grants and publish only the complete tile. A stable held tile thus has a path to the device even at high DPI. Never postpone every tile-only repair behind an endless series of zero-grant edits; schedule the oldest with a positive sliced allocation.

Charge byte copies, cell validation, metadata checks, FIFO recovery and row/run enumeration to one shared deadline/credit, starting at UI step entry. Split long rows, region scanlines and bitmap clears. Check input before resumption. Set maximum indivisible chunk from measured worst observed cost with headroom for wake, validation and handoff. Use elapsed time as well as item credits; a check after an unbounded memcpy cannot enforce a slice. INIT/reprovision prepay and touch all UI-hot storage via base arenas/pools. The *whole* ingress→mutation→follow→compose→submit path must see an active release malloc guard and zero counted allocations, including callbacks and concurrent work counted by the process guard. Move potentially allocating native calls outside this guarded interval or isolate/serialize native work so it cannot contribute a counted allocation. Verify with pending native packets and guard actually active.

As a scale check, the oracle's A-machine contiguous memcpy after idle is about 9.1 GB/s payload (M [AC], 20 MB / 2.19 ms, load unreported). At that rate the 360×300 full cell copy alone is ~238 µs (E, 2,167,200/9.1e9 s), the single row ~0.8 µs (E). These exclude validation, cache scatter, region, input and device issue. R2 cites wrapped Unicode full layout p99 499.9 µs [AC, load1 4.54] and 1,333 µs [AC, load1 6.91] at that fixture (M). An entire additional 0.5 ms prep slice on the latter would leave only ~0.167 ms of the 2 ms goal for all remaining work (P arithmetic, illustrative, component percentiles do not add to a joint p99). A frame-size cap alone gives no time guarantee. No measured v2 tile cap, UI slice pass, integrated G1 pass or GL winner is claimed. Record the actual caps and cold/warm joint distributions at the largest admitted grid and DPI, on battery/AC with load, in the implementation lane.

render_cell_span is a const pointer and checked count. Source row indices include fixed rows and a distinct extra index for overscan. During a tile-only repair use the last accepted stamp with a new composition serial and no new input association; the scene and hit binding remain paired. Such a repair uses only already composed slot versions. A font settlement that changes producer cells requires a fresh paint offer.

**render/render.h service functions** (L5 front door). A render_source adapter is UI-owned for the attempt. Its stamp and immutable publication identify the same picture on every step. It supplies indexed canonical runs, a const source-row span including explicit overscan, a region view, current identity by slot, and a tile view for selected slot/version. These are function pointers in a value table with a context; no L4 type enters L3. Identity validation for a changed cell is an indexed metadata read. Never pull its pixels to check it. The UI-side source owner calls image_changed for every settled/reassigned/removed runtime version, including during recovery. Sources and notifications can be exposed to L5 through a rendering facade whose adapters live with the supplying modules. The renderer includes render_types and public platform/base/work types, never font_async.h or layout.h.

render_rc render_measure(const render_binding *, const render_limits *,

render_rc render_begin(render *, const render_offer *, render_need *);

~~~

Setup gives admitted limits, prepaid storage/workers, selected public driver descriptor and native binding from plat_native.h. Bind admits/installs a caller-owned sheet by copying it into independent setup storage before releasing its CPU owner. Immutable baked constants may be read directly during setup. OPENING/bind/close use MORE for runnable steps or WAIT plus a wake for outstanding physical work. A new binding is visible only when ready. Offer carries stamp, last accepted base, full/patch mode, layer damage, dimensions and lengths with no borrowed row pointers. Step yields MORE for a partial cursor; OK means fully staged. Grant holds remaining time and item/byte credits. Zero credit does no copy. Accept returns the committed ID only on success. Abort is legal only before handoff. Events route typed platform feedback or work messages through the public boundary. Stats carry accepted ID/input mapping, reject reasons, bytes, correct clock domains and terminal outcome.

**render/render_submit_prep.h** (private to render). One embedded opaque prep cursor suffices at depth one. Proposed function groups:

~~~c
render_rc render_prep_begin(render_prep *, const render_offer *, const render_base *,
                            const render_limits *, render_packet *, render_need *);
render_rc render_prep_step(render_prep *, const render_source *, render_queue *,
                           render_grant, render_need *);
void      render_prep_commit(render_prep *, render_queue *, render_frame_id);
void      render_prep_abort(render_prep *, render_queue *);
~~~

Begin checks scalar extents/base and initializes cursors; step validates canonical runs, cells, tiles and fixed region while copying. Commit seals the owned packet and advances delivery exactly once after the final validity check. Abort drops the private cursor and leaves the queue retryable. No per-backend check/packer duplicates these functions.

**Backend-facing public render driver declarations / private consumption.** Expose render_driver_null(), render_driver_xshm() and render_driver_gl33() as descriptors in a render public header, implemented by the respective backend modules. A public selection adapter at the L3 integration edge binds these factories to the platform choice. Common render accepts a descriptor by value and never links upward into its consumers. L5 uses public plat.h, plat_native.h and render headers only. The driver SPI accepts the sealed packet from a single command slot. Its operations are query_caps, open, bind, consume, poll, quiesce and close. Consume orders apply/draw/issue; poll yields authenticated ISSUED, DEVICE_DONE, PRESENTED, DISCARDED or LOST notices with original identity/time. Both operations run on the owning side of the native connection/context. Only the UI common adapter advances the public FSM and emits ordered traces. Public selection, callbacks and wake plumbing must respect the PLAN §2 include DAG. No L5 X event decoder, GL buffer lease or raster-specific caret call.
