## 6. Decisions and attribution

**Bptree remains the base.** Keep 16-way B+ path sharing, leaf-local splices and merge rules,
64 KiB immutable append chunks, retired directories, atomic node/core lifetime, lazy atomic
exact newline caches, and complete ref collection. Delete still copies ORIGINAL bytes even
when `ref == NULL`, as the frozen header requires. No `piece_*` function creates threads.
Cold counting is serial; P1.6 lineidx/src/work owns bulk worker scheduling. The wrapped
32 MiB mapped-query regression finds 14 pthread creations in plain bptree and 0 here.

**Flat cursor cache, adapted to B+.** Cache the leaf, slot, byte start, and ancestor indices.
Only an entirely exclusive path is eligible. Appending, backspacing and bounded leaf-local
inserts update ancestor byte/newline summaries without root lookup. Structural edits and
snapshot takes invalidate the cache; shared paths are copied before writes. The cursor test
proves 1,000 successive appends take 0 root descents versus 1,000 on the base. It also checks
snapshot isolation across the next append. Keep bptree's append-run rules, not flat's array
memmoves or O(pieces) snapshot copies.

**Rope packing principle, with flat-width leaf fields.** Remove bptree's 48-byte header padding,
use 16-bit count/kind fields, and narrow leaf byte/newline entries to u32 because every piece
is at most 64 KiB. Keep u64 branch aggregates and the existing unknown-count bit semantics.
Separate 272 B leaf/snapshot and 400 B branch classes replace the single 448 B class. The
2 MiB snapshot-edit regression copies 672 B instead of 896 B (M)[bat]. This borrows compact
layout rather than rope's AVL topology: the original Pareto table shows rope's random edits
slower, and re-descending per piece also sacrifices B+ leaf iteration.

**Flat's unchanged-version cache, adapted to snapshot headers.** Repeated takes share one
immutable header/root and do O(1) atomic retain. Every public owner, including retain, gets
its own mapping acquire/release; the private cache uses the tree's mapping owner. Mutation
uncaches before COW. This fixes the live-header bound without copying a piece array.
The repeated-snapshot regression is red on plain bptree and green here, including 101 mapping
owners for a tree and 100 public snapshots of an empty mapping.

**Keep lifetime, failure atomicity and trimming fixes.** Successful edits mark initialization
permanently, even if later deleted to empty. Empty mapped trees acquire their mapping owner.
Mutation reserves all needed storage before changing content; the failure sweep exercises
233 allocation failures with tree and live snapshot unchanged and no leaks. Tiny fixed slabs
(4 nodes, 1,104 / 1,616 B requests) and owner-only trimming meet the small/retired-pool G10f
regressions. Trim only after core rc==1, which synchronizes completed remote returns. Shared
nodes, immutable bytes and atomically cached counts remain readable from snapshot threads.
Allocator hooks handle all requests; the release arena typing test observes 0 malloc calls
through 10,000 edits plus snapshots. Only the TEST-ONLY default allocator wraps malloc/free.

**Drop hybrid gap blocks after trial.** The inherited prototype is preserved as
`build/synthesis/gap_trial_full.c`. It stores small inserted ranges in refcounted 256 B gap
blocks, clips iterator spans around the gap, and performs exclusive local deletes without
creating a second piece. It also keeps immutable canonical add bytes for the strict reference
contract. Its isolated test is red on plain bptree and green on the trial; the saved frozen
suite run also passed. This was a limited inserted-range prototype, not a completed port of
hybrid's +/-48-byte mapped-original window policy.
