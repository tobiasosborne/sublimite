# v2-1sg viewport decisions

The implementation follows the signed [Wave 2 viewport and layout contract](wave2-viewport-layout-spec.md) and [A29](wave0-plan-amendments.md). It implements the public declarations with signed errata E5 and E6 and keeps the PLAN §2 layer order. The viewport cursor owns only intent state and prepaid scratch. The caller owns the snapshot, read cancellation, row certificates, final placement and presentation.

## Mechanisms

| Mechanism | Invariant | Simplest alternative and counterexample |
|---|---|---|
| Intent and acceptance | Begin copies the intent. A MORE step preserves its next request and leaves the caller's answer untouched. Acceptance compares buffer incarnation, text and geometry, and intent serial before installing top and selection. | Check the byte and geometry alone. A second edit or tab bind can produce the same byte and geometry while the first read is outstanding. |
| Rebase | The replacement maps interior points and insertion ties according to gravity. The old right edge of a nonempty deletion travels with the unchanged suffix. | Treat the right edge as consumed. Before-gravity would move an anchor at the first surviving suffix byte to the beginning of its replacement. |
| Pixel plan and scroll | The plan covers the intersecting row intervals, including a partial bottom row. Hit inversion uses that same Q8 origin. Relative scrolling uses floor division with a nonnegative modulus. Splitting the dividend before adding the remainder covers the entire signed delta domain. Scroll and reflow resolve the starting row, then request unit row steps. A step that returns its source saturates the remainder to zero. An in-range step onto the first or last row preserves the modulus. | Use C's signed division directly or store a row fraction. A step above a row boundary produces a negative remainder in C. A clamped bulk neighbor can return byte zero for both a one-Q8 in-range position and an overshoot. |
| Grid and cluster motion | A row certificate gives the canonical display-line start. A stage walks from there through LF or the next aligned raw grid, including only the fixed UTF-8/CRLF halo. It preserves short raw windows and segmentation state across grants. The signed S1 bound is D = 2S + 4, with S = 32,768 from A29. | Restart from an arbitrary caret or split at the raw grid. The 2S + 2 witness shifts the cut by three bytes inside a valid four-byte scalar, and a CR at the previous byte can need the LF at the grid. A stray continuation is a single invalid unit. |
| Directed word walks | The first scalar gives the pin's cluster class. Synthetic seams reset segmentation and leave word runs connected. Reverse traversal stages a display line once and visits its cluster starts and classes backwards. Select Word completes the right side and uses a saved seam to continue the left side without restaging the active line. | Stop words at seams or scan repeatedly from the physical line start. The first cuts a continuous identifier and the second repeats segmentation inside the same line and can walk an unrelated prefix. |
| Physical LF bounds | Rank/select results are used when exact. For a nonempty selection the high occupancy probe is the byte before its exclusive end. Reverse scan for the low bound and forward scan for the high bound consume disjoint ranges. An inexact forward select can advance the scan to its exact prefix when that prefix proves the next LF is still ahead. A collapsed inexact rank can drive both missing bounds. Repeat extends by one line. | Always scan for LF or treat an inexact select as an exact start. The former walks a long line even when E4's index knows the answer. The latter can stop inside the first unknown piece. |
| Selection and affinity | Plain motion collapses the mark. Shift retains it. Horizontal motion clears preference. Vertical motion latches the source screen column, including indentation, and uses the destination row to choose seam affinity. End uses the drawable end before the terminator. Ordinary Home uses the active visual row in both modes. | Treat one byte as one screen position. At a shared wrap or synthetic seam its trailing and leading positions belong to different visual rows. |
| Visual displacement | Page moves the caret and top once each by the count of fully visible rows, bounded per operand by the frame's admitted R. For fractional scroll, the partial first and last rows contribute to R but have no whole-row credit. Placement receives the resulting top and committed-selection proposal. | Move by R including overscan. From a fractional first row this crosses a page's worth of fully visible text and the clipped rows as well. |
| Decoder grants | Prepay the maximum bytes a decoder call can inspect from its lead and available tail, including the separate class decode where needed. Pay fixed seam probes before alignment. Carry partial payment for a unit across grants and count it toward the 4,096-byte ceiling on the step that decodes it (G, S4). Reverse traversal pays one credit per summary. | Debit one per call. A line of four-byte U+E0100 combining scalars then advances by 16,384 bytes on a 4,096-credit step. Requiring the complete unit's credit in one grant would stall a caller that supplies one credit at a time. |
| Reflow preference | Compare the old width in a REFLOW intent's `target` with the new frame width. Preserve the preferred column on a height-only change even when reflow crosses a row. At acceptance compare the installed wrap with the requested wrap and clear preference and horizontal origin on a toggle. | Clear on every reflow. Returning to a wide row after a height-only change then uses a new column latched on the shorter row. |
| Flat port service | Eager fixture construction records cluster boundaries, columns, and row/rank lookup at each byte. Window bytes and each destination-column visit consume credit. A pending column lookup resumes at its cursor. | Scan the full row inside a one-credit source-row callback. The benchmark's predecessor request at S−1 then hides 32,767 cluster visits inside a single call. |
| Future callers and link isolation | The public symbols are reserved against the signed specification. The pre-existing isolated L4 link test exercises the viewport header and wrap default. The executable smoke path reaches the existing render smoke directly after the removal of the viewport placeholder. | Keep a viewport smoke export taking a render dependency. It would add a public symbol to the signed API and put rendering back on the viewport dependency path. |

## Advisor rulings and remaining integration decisions

- **E5 (Q1), signed.** The driver supplies the bound snapshot's length once, including zero, to `viewport_motion_begin`. Evidence drops the length member. DOC_END and SELECT_ALL issue no port queries. Each VP_ROW answer supplies the queried byte and affinity's `screen_column`, including continuation indent. `count` carries logical rank or a select prefix count.
- **E6 (Q2), signed.** Home is visual in clip and wrap. The grid row at S starts Home on an S+1-byte ASCII document even when its physical line starts at BOF. Wave 2 has no physical Home action. Piece rank/select and raw LF fallback remain selection mechanisms for SELECT_LINE.
- **Reflow representation (Q3).** The signed header exposes one width and one proposed wrap value. This implementation uses `target` for the previous width in REFLOW, in pixels, including a previous zero-width clip. The driver must set it on every REFLOW. The installed wrap is available at acceptance.
- **Saturation and placement (Q4 and Q5).** Unit neighbors supply the clamp proof for scroll and reflow without adding evidence fields. Page still sends a displacement no larger than R for each operand and uses the destination row's column if it differs from the source row. Layout owns margin, minimum reveal, EOF backfill and accepted geometry. The intent and answer carry the committed selection, affinity, origin and Q8 remainder. The frame has no margin field.
- **Rank wake.** The port driver has the rank observation serial and owns the wait. An inexact SEEK_LINE suspends with its tagged request unchanged. On repeated ticks with the same observation the integration port should keep waiting or replay cached inexact evidence so that piece receives one indexed attempt per new observation. The viewport API has no wake token with which to distinguish a new rank observation from more CPU credit.
- **Joined-cluster snapping (Q6).** Rebase transports offsets. The owner with current text evidence must resolve a mapped point to a legal cluster edge with the requested affinity. Top uses leading affinity.
- **Staging ownership (Q7).** The opaque cursor owns one source and reverse-summary set with a bounded resident window. Layout's placement storage follows S4. Fully retired storage can be recycled when lifetimes are disjoint.
