# P1.8 work: worker pool + UI mailbox

- Pool storage is caller-owned (`work_pool`, ~150 KB static); no allocation in the module. Threads are created once in `work_pool_init` (1 bulk, 0..8 raster), each calls `trace_thread_register`.
- Sync: one mutex + one condvar per class guards two fixed FIFO rings of slot indices (64 in-flight jobs). Idle workers block in `pthread_cond_wait`: zero wakeups when idle (G11). Everything on the hot path (generation, mailbox indices) is C11 atomics.
- Cancellation: each job slot has an atomic `epoch`. Submit bumps it and the handle carries it; the ctx snapshots it. `work_cancel` stamps `cancel_ns` (relaxed), then CAS epoch -> epoch+1 (acq_rel). `work_should_stop` = one acquire load + compare. A queued job whose epoch changed is skipped by the worker without running. A stale handle is a no-op (CAS/precheck), slot reuse is safe because submit bumps the epoch.
- `Job.generation` is the caller's tag (e.g. document/buffer generation); it is copied to `ctx->generation` and the job copies it into `work_msg.generation`. The module's own staleness is the per-slot epoch, so a cancel is O(1) and needs no shared counter. This is a small deviation from "cancel bumps the generation".
- Publication: per-worker SPSC ring of 256 x 64 B. `work_publish` drops if the job is stale or the ring is full (counters `dropped_stale`, `dropped_full`), then writes the eventfd. `work_mailbox_drain` (UI) reads the eventfd, pops and re-checks the epoch, so messages published before a cancel but not yet drained are also suppressed.
- Shutdown: set flag, bump every epoch (running jobs see stop, queued jobs are skipped), broadcast, join. A running job that never polls blocks shutdown; that is the polling contract (<= 5 ms).
- Limits: n_bulk must be 1. Submit returns epoch 0 handle when 64 slots are busy. Slot is freed when the worker is done, so a cancelled-but-running job holds its slot until it returns.
- Measured [AC]: cancel->ack p50 3.4 us, p99 11 us (gate 1 ms / 5 ms); submit->start idle p50 5.1 us, p99 77 us.
