# Wayland platform dispatch and presentation

The shared platform ABI remains in `src/x11/plat.h`; `src/wayland/plat.h` forwards it and exposes native EGL/presentation helpers. Legacy `plat_init` keeps X11 as its default. `plat_init_backend` selects explicitly, and the editor accepts the platform choice in its configuration. Main makes that choice before the X display safety redirect: a nonempty `DISPLAY` wins, otherwise a nonempty `WAYLAND_DISPLAY` chooses Wayland. IPC uses the selected display's name.

The Makefile probes the client/EGL/xkbcommon headers. Without them, the module compiles dependency-free stubs and selecting Wayland fails cleanly. The protocol glue is generated from stable upstream xdg-shell and presentation-time XML, with upstream licences retained. Server headers independently enable the headless test/fuzzer; libwayland-server is linked only into those executables. This bead's explicit Makefile-probe requirement overrides the tree's general instruction against Makefile edits.

Wayland owns its display, registry, compositor, xdg surface/toplevel, seat, keyboard, pointer and native EGL window. An empty surface commit and xdg configure acknowledgement precede any EGL buffer. Toplevel dimensions are staged until the serial-bearing surface configure; a zero dimension preserves the client choice independently of the other dimension. The existing GL worker loader continues to dlopen EGL/GL; it chooses the Wayland platform display and native window for this backend. Shader/fence warm-up uses the prepared initialization draw on that worker without a Wayland buffer swap. UI operations begin only after worker handoff. The X11 raster fallback cannot serve a Wayland surface and is rejected rather than opening an unrelated X connection.

Every submitted GL frame requests a frame callback and matching `wp_presentation` feedback before swapping. The frame callback is a scheduling hint; it neither acknowledges display completion nor delays another already eligible frame. The GL fence remains the device-completion source for T5. Only matching presented feedback acknowledges T6, using the compositor's monotonic timestamp when available; other clock domains use observation time instead of passing an uncorrelated clock to tracing. Discarded feedback is a device error, and stale/duplicate frame identities cannot release a newer frame. Absence of presentation feedback support causes GL init to fail explicitly.

The event loop uses Wayland's prepare/read/cancel protocol and polls flush backpressure, native input, blink/repeat timers, the borrowed work descriptor and clipboard pipes together. It delivers native input before a simultaneously ready worker/blink callback can end the pump and submit older content. It drains buffered input before waiting and cancels repeat on release, keymap replacement or focus loss. Key translation and its fixed queue allocate nothing. Keymap and compose construction, native protocol transport and clipboard storage stay outside the input-to-submit slice.

Pointer axes use protocol detents when provided, preferring value120/discrete data to accompanying continuous values within the same pointer frame. The value120 conversion is (P): protocol units per detent mapped to `PLAT_WHEEL_UNIT` per notch. Legacy continuous-only conversion is (E): the libinput convention of ten surface units per wheel notch; it is not a measured scroll-distance claim.

Clipboard uses UTF-8 offers, a serial-bearing data source and asynchronous pipes. Reference-counted snapshots keep active sends valid across ownership changes. Incoming bytes use separate staging storage; publishing a completed result preserves the previous borrowed result until that completion. Local reads also publish through the event pump. Transfer slots and owned-byte ceilings inherit the existing X11 clipboard capacities, rather than introducing a new budget. Primary selection needs a separate extension and returns unsupported/failure through the existing interface.

The mock compositor uses a private socketpair. This sandbox denies `SO_PEERCRED` even on that socketpair, so the test/fuzzer supplies its known forked peer credentials to libwayland-server. No production authentication override is linked. Protocol marshalling, file descriptor passing, keyboard keymaps, pipes, configure/ack and presentation messages remain real. The separate GL integration test mocks only the device fence; it does not claim to exercise EGL hardware.

The benchmark exercises the production editor, minimap and GL adapter with synthetic platform ingress. Its sample policy and target viewport come from the existing interaction harness and editor benchmark. Timing values derive from ingress-to-backend T4 for the first matching key sequence (G1) and ingress-to-device completion for that same frame (G3); unrelated caret frames cannot replace the measurement. The full-frame workload pairs page navigation with exposure and verifies full repaint; negotiated buffer dimensions are printed. Nearest-rank percentiles use the shared harness. It runs only with explicit `--run PATH [SAMPLES]` and never fabricates results when no compositor is available. Live measurement and the next Astra comparison remain coordinator work.
