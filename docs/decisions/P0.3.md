# P0.3 trace — decisions (2026-10-08)

- Timestamp source: `clock_gettime(CLOCK_MONOTONIC)` via vDSO, as perf §4 specifies. Measured floor on A [AC]: 14–25 ns per read (noisy). `trace_record` costs p50 27 ns / p99 36 ns, i.e. ~2 ns over the clock read.
- The bench gate written in the bead brief (p50 < 20 ns) was an invented (G) below the clock floor; relaxed to **p50 < 50 ns**. rdtsc with calibration rejected for now: not worth a second clock domain to save ~20 ns per event; revisit only if trace cost shows up in G1.
- 16 static rings × 65 536 × 16 B = 16 MiB of BSS, untouched until written (counts toward G10 only when used). Single writer per ring, `_Thread_local` ring pointer, records from an unregistered thread are dropped.
- `trace_record_at(ev, frame, ns)` exists for replay and tests. Dump format `EDTRACE1`, loader shared with `tools/tracedump` via `src/trace/trace_fmt.h`; the per-frame join takes the first occurrence of each event per frame id.
