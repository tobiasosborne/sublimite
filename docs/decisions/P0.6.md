# P0.6: deterministic input record/replay (edit-yy5.6)

## Record
`trace_input_rec`, 48 bytes, zero-filled on append (dumps are byte-exact):
`seq u64` (monotonic since init/reset), `t0_ns u64` (CLOCK_MONOTONIC ingress stamp), `kind u16`, `flags u16`, `reserved u32`, 24-byte payload union.
Kinds: 1 key_down, 2 key_up (keysym, xkb state, repeat, utf8[8] + len, clipped to 8), 3 pointer_move, 4 button_down, 5 button_up (x, y, button, mods), 6 wheel (dx, dy 16.16, mods), 7 resize (w, h), 8 focus, 9 clipboard arrival (selection, length), 10 file change (watch_id, flags). 0 is invalid.

## Ring
Static ring of `TRACE_INPUT_CAP` = 16384 records (768 KiB), single producer (UI thread), overwrite-oldest, `dropped = total - cap`. Append is a memset + field stores, no allocation, no atomics (readers run while the producer is quiescent, same contract as the timing rings). Reset in `trace_init` and `trace_reset`.

## Dump format and versioning
The version-1 header is unchanged. After the per-ring blocks an optional section is appended:
`tag 'INPT' (0x54504e49) u32, version u32 (1), rec_size u32 (48), count u32, dropped u64, count x record`, oldest first. Old (pre-P0.6) loaders stop after the rings and ignore trailing bytes; new loaders accept dumps with or without the section. Future sections must bump the section version or use a new tag.

## Validation (`trace_fmt_load_dump`, src/trace/trace_load.c)
Rejected: bad magic, header version != 1, rec_size != 16, ring_cap != 65536 (stricter than before: bounds allocation), nrings > 16, ring count > cap, truncation anywhere, unknown tag, section version != 1, rec_size != 48, count > 16384, seq != dropped + index, kind 0 or >= 11, t0_ns going backwards, key utf8_len > 8, any bytes after the section. On failure the output struct is zeroed (nothing to free). Type is named `trace_loaded` because `trace_dump` is the writer function.

## Replay timing
`trace_replay` waits on absolute CLOCK_MONOTONIC deadlines `start + (t0_i - t0_0) / speed` via `clock_nanosleep(TIMER_ABSTIME)`, EINTR retried. Sink latency and scheduler jitter do not accumulate; delivery is never early. `fast` skips waiting. speed must be finite and > 0. Sink runs on the caller's thread. plat.h wiring is a later bead.

## Gate
Input append is held to the same 50 ns per-record gate as `trace_record`. Measured numbers are in the bench output (see worker report).
