# edit-cxho.20: Win32 drag-and-drop open

1. **Transport.** WM_DROPFILES -> DragQueryFileW (length probe, then exact buffer, so paths past MAX_PATH work) -> UTF-8 -> one `text/uri-list` CRLF line per path in `win32_plat.drop_data`; PLAT_EV_DROP carries the drop point. `plat_drop_data` returns that buffer (borrowed until the next completed drop or shutdown), per plat.h.
2. **URI shape.** `C:\Users\x y\ü.txt` -> `file:///C:/Users/x%20y/%C3%BC.txt`; `\\host\share\f` -> `file://host/share/f`; `\\?\` and `\\?\UNC\` prefixes are stripped first. Everything but `A-Za-z0-9-._~` and the separators is percent-encoded (so `#`, `?`, `%` survive). Relative or non-absolute entries are skipped.
3. **src/dnd under _WIN32.** `file:///C:/a/b` maps to `C:\a\b` (leading slash dropped, `/` -> `\`); a non-local authority is a UNC server (`\\host\...`, authority percent-decoded, `@ : [ ] \ ? #` rejected). Linux code path is byte-identical (`#if defined(_WIN32)`); foreign hosts still rejected there. Bare `/abs` paths are untouched on both.
4. **Failure policy.** An entry that cannot become UTF-8 (NTFS permits lone surrogates) is skipped and the rest are delivered. If nothing remains, or allocation fails, the previous drop data is kept and NO event is raised. DragFinish always runs.
5. **UIPI.** Decision: act only when the process token is elevated. Then `ChangeWindowMessageFilterEx(MSGFLT_ALLOW)` for WM_DROPFILES, WM_COPYDATA and 0x0049 (WM_COPYGLOBALDATA, which Explorer's drag sends). A non-elevated editor shares integrity with Explorer and needs nothing; widening the filter there would only enlarge the attack surface. Untestable here (not elevated); on the live-check list.
6. **Leave (edit-osn3, Win32).** TrackMouseEvent(TME_LEAVE) is armed on WM_MOUSEMOVE when `tracking` is false (one-shot); WM_MOUSELEAVE clears it and pushes the existing PLAT_EV_LEAVE (as X11 does, with the last pointer x/y). No plat.h change.
7. **Path contract for editor.c ~640 (not edited).** `stat(request.paths[i].path)` needs a UTF-8 path the CRT can open: the UTF-8 activeCodePage manifest makes mingw `stat` take UTF-8, and drive and UNC paths with backslashes work (verified in the test). `gethostname` there needs Winsock (WSAStartup) on Windows; and S_ISDIR/`struct stat` must be available from the port. Those are for the editor port.
