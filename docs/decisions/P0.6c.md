# P0.6c: replay minors (edit-yy5.9)

- `tools/replay --speed` now rejects non-finite and non-positive values itself (`inf`, `nan`, `0`, `-1`) with `replay: --speed must be a finite number > 0` and exit 2; `trace_replay` still rejects them (test added in `tests/replay_test.c`).
- Wheel deltas are documented in `trace.h` as 8.8 fixed point in `PLAT_WHEEL_UNIT` units (256 per notch), matching `src/x11/plat.h`. No code conversion existed in trace/replay, so none was added. `src/trace` does not include `plat.h`.
- The tool-level check is a shell script (`--speed=inf` expects rc 2 and the message), kept outside `make check` because the Makefile is off-limits to this bead.
