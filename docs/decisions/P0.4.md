# P0.4 bench harness — decisions

- Confidence interval is 95 % (normal approximation to the binomial order-statistic ranks); functions and the report field are named `ci95` accordingly.
- The report line's `ci95=` is the interval for the median. p99 intervals are available via `bench_ci95(s, 0.99, …)` but not printed.
- `bench_p` / `bench_ci95` heapsort the caller's buffer in place (no allocation); insertion order is lost, the multiset is unchanged.
- Any dropped sample (buffer full) or an empty set makes `pass=0`: failures and timeouts are never excluded (perf §4).
- No libm: sqrt by Newton iteration, so the header links anywhere.
