# P1.2 scan — Pareto decision (2026-10-08, [AC] "Not charging")

Three variants, same API, 1 GiB cached, 70-byte lines, ~2 % non-ASCII, 20 runs, gate ≥ 12 GB/s p50.

| Variant | .text bytes | scan_count p50 / p99 GB/s | find_nth_newline p50 / p99 | Fallback |
|---|---|---|---|---|
| **sse2** (chosen) | 880 | 15.30 / 12.16 | 17.22 / 16.54 | none needed: SSE2 is the baseline |
| popcnt | 2505 | 14.45 / 13.73 | 16.52 / 16.10 | generic |
| avx2 + sse2 fallback | 1825 | 15.65 / 15.21 | 16.65 / 15.99 | its SSE2 path: 5.54 / 7.55 (misses) |

sse2 dominates popcnt on both axes. avx2 wins scan_count p50 by 2 % (noise level) at 2× code, and its fallback would miss the gate on Target C (SSE2-only). Chosen: sse2 (byte-lane accumulators with SAD flushes, no popcount, no tables). Consistent with perf §3 "AVX2 is optional". Variants kept under variants/P1.2/ until the P1.R review, then deleted.
