## Contract changes (additions only, `src/ipc/ipc.h`)
Constants IPC_DRAIN_*, IPC_REQUEST_DEADLINE_MS, IPC_EVICT_IDLE_MS, IPC_LOCK_TIMEOUT_MS, IPC_RX_*; `ipc_server` fields

ipc_server_init_isolated, ipc_launcher_pair, ipc_server_adopt_wait, ipc_launcher_wait. Behaviour: init may return

## §1 Encoder overruns when input aliases the output (BLOCKER)
Verdict: valid. Writing the header rewrote strings that were still being measured/copied.
Fix: `overlaps()` in wire.c; cwd, every path and the stdin range are rejected with IPC_INVALID when they intersect the
output capacity, before anything is written. Test `wire_alias`.
Red: `FAIL g.canary[i]==0xA5` (guard bytes past the output were clobbered). Green: suite ok; fuzz Part 3 asserts it on
every input (verified red by removing the check: `ipc_fuzz.c:210 ... ==IPC_INVALID`).

## §2 Runtime-directory races allow chmod of an attacker-chosen file (BLOCKER)
Verdict: valid (path-based chmod/unlink after a directory swap).
Fix: the runtime directory is opened once as an O_PATH|O_DIRECTORY fd and verified (owner, mode); bind,
unlink, lock open and chmod go through openat/unlinkat or `/proc/self/fd/<dirfd>`; the socket is identified by
device/inode. Test `runtime_swap`.
Red: `FAIL lstat(moved_sock)...` (the swapped directory's socket was touched). Green: ok.

## §3 Canonicalization redirects invalid paths (BLOCKER)
Verdict: valid (`leaf/../victim` resolved after lexical collapse through a non-directory).
Fix: canonicalization checks each prefix with lstat; a file prefix followed by anything else is ENOTDIR, as the kernel
would report it (IPC_INVALID), and a trailing slash demands a directory. Test `parser_paths`.
Red: `leaf/../victim rc=0 path=.../victim`. Green: IPC_INVALID, ok.

## §4 Suffix parsing mistakes filesystem errors for an absent filename (BLOCKER)
Verdict: valid (`a:1` where `a` is a file with an error on stat was split).
Fix: an existing whole filename (lstat succeeded) wins over suffix parsing; only ENOENT permits trying the suffix;
ENOTDIR is IPC_INVALID and any other lstat error is IPC_IO. Test `parser_paths`. Red/green as §3.

## §10 Drain bounds events but not UI work (MAJOR)
Fix: per-call budgets IPC_DRAIN_BYTES (256 KiB), IPC_DRAIN_CALLBACKS (8), IPC_DRAIN_ACCEPTS (8); unread bytes stay in
the kernel, the level-triggered epoll fd re-wakes the loop. A callback is only reachable via a recv, so always has
budget. `drain_bytes` exposes the last call's volume. Test `drain_budget`.
Red: `drain ran 24 callbacks in one call (budget 8)`. Green: ok.

## §11 Incomplete clients permanently exhaust all slots (MAJOR)
Fix: a timerfd (armed only while an incomplete peer exists) enforces IPC_REQUEST_DEADLINE_MS (5 s) per request;
under slot pressure peers idle longer than IPC_EVICT_IDLE_MS (500 ms) are evicted so a new connection is served.
Test `slot_exhaust`. Red: `deadline timer never woke the loop`. Green: ok.

## §12 Lifecycle locking can block startup/shutdown indefinitely (MAJOR)
Fix: flock is taken LOCK_NB in a bounded retry loop (IPC_LOCK_TIMEOUT_MS = 1 s). Init returns IPC_TIMEOUT; fini that
cannot lock leaves the socket for the next startup's stale recovery instead of unlinking blind. Test `lock_timeout`.
Red: Alarm clock (exit 142, init hung). Green: ok.

## §13 Predictable abstract names can be squatted (MAJOR)
Fix: peers are credential-checked both ways (SO_PEERCRED uid == ours) on server accept and in the client; a client
refuses a foreign server (IPC_REJECTED) and the server drops a foreign client without a callback or ACK. If another
uid squats the abstract name, init falls back to a private filesystem endpoint (EDIT_IPC_FALLBACK_DIR or
/run/user/<uid>). Hook EDIT_IPC_TEST_PEER_UID models a foreign uid, abstract endpoints only. Test `foreign_cred`.
Red: `client foreign-server rc=6` (client accepted the foreign server). Green: ok. Open: no /tmp fallback if both
/run/user/<uid> is absent and the name is squatted (IPC_EXISTS).

## §14 IPC reserves 33.56 MB outside the memory plan (MAJOR)
Fix: a shared receive pool of 16 x 64 KiB + 2 x 1 MiB = 3 MiB (plus peer table); buffers are acquired after the
header is validated and released as soon as the callback returns. Exhaustion answers an IPC_BUSY ACK (bounded
admission) and small work keeps flowing. Test `memory`; `ipc_bench` now asserts pool == 3 MiB and arena <= pool+256 KiB.
Red: `ipc arena is 33561088 bytes`. Green: ok.

## §15 Disconnect cleanup for wait associations missing (MAJOR)
Fix: `wait_drops` counts wait clients that vanished before their closed reply; `ipc_server_token_live(token)` answers
whether the client behind a token is still connected. Contract: after any drain that raised `wait_drops`, the loop
sweeps its token associations and drops entries that are not live (at most IPC_MAX_CLIENTS live). Test `wait_disconnect`.
Red: `token 1 still live after disconnect`. Green: ok.

## §16 Primary launch does not implement --wait (MAJOR)
Fix: `ipc_launcher_pair` creates a socketpair before the UI starts; main fork()s, the child (UI) calls
`ipc_server_adopt_wait(fd)` and associates the token with the initial request, the parent blocks in
`ipc_launcher_wait` and exits with its result when the closed reply arrives (IPC_IO if the UI dies first).
`ipc_server_init_isolated` serves `--new-instance` without touching the shared endpoint. Test `launcher`.
Red: `FAIL ipc_launcher_pair==IPC_OK` (stubs). Green: ok.

## §17 Tests/fuzz cannot detect protocol/security regressions (MAJOR)
Decoder half (`wire_table`): a table of structural mutations; it was already green (decoder was strict).
Fuzz half (edit-457.21b, `fuzz/ipc_fuzz.c`): an exact-result oracle. Each input builds a model request, encodes it and
applies one of 17 structural mutations (truncation, trailing bytes, magic, version, flag bits, reserved bytes, total /
count / cwd / input / path-length fields, zero or changed line/col, missing leading slash, replaced terminator,
interior NUL, wait/stdin flag toggles, payload byte). The model predicts IPC_PROTOCOL or an exactly equal request;
anything else traps. Part 3 checks the encoder (LIMIT on short capacity, INVALID cases, aliasing, determinism,
new_instance not serialized). Part 4 (1/32 of inputs) runs the mutated envelope through a real abstract-namespace
server: ACK code equals the model, the callback sees exactly the expected request, and a peer with a foreign uid
(hook) never reaches the callback or receives an ACK.
Regression checks (each reverted afterwards): reserved bytes unchecked -> `ipc_fuzz.c:71 rc==IPC_PROTOCOL`;
encoder alias check removed -> `ipc_fuzz.c:210 ...==IPC_INVALID`; SO_PEERCRED uid comparison removed ->
`ipc_fuzz.c:116 s.calls==0 && got!=8 && got!=-2`.
`ipc_test --parallel [N [ROUNDS]]` (default 4 x 1) runs N independent suites with distinct EDIT_IPC_NAMESPACE values
(reported over a pipe, checked pairwise) as the isolation regression; `make check` runs the serial suite only.
