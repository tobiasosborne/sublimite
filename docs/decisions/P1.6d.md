# P1.6d — lineidx benchmark review fixes (edit-4w1.48)

Scope: bench plus this decision and lineidx STATUS.md. No module implementation,
frozen header, Makefile, coordinator document or fuzzer changes.

## §15 — accepted: fresh jump through viewport submission

Every sample checks zero built chunks and no build before the request. Its timer
covers bulk-worker submission, full index publication, target lookup, sliced
80×24 layout and null-backend submit/present; source retirement is untimed.
Worker callback byte accounting must equal the fixture size in every sample.
Independent checks verify all row starts/cells and reject deliberately corrupted
cells and an already-built index. One bulk worker is active during the request;
mailboxes are drained during waits and between repetitions.

The public API has no worker seek continuation. G7j therefore pays for a full
worker build. Proposed **lineidx** follow-up, outside this bead: cancellable
immutable-snapshot seek, stopping at the requested target, publishing the offset
through src/work for UI layout. No piece/render/find header change is needed.

`make build/bench/lineidx_bench`; `--self-check=15` (exit 1 → 0):
```text
SELF_CHECK 15 FAIL fresh_prefix=2 viewport_submitted=0
SELF_CHECK 15 PASS fresh_prefix=0 viewport_submitted=1
```

## §16 — accepted: independent oracle and fixture manifest

A scalar loop counts newlines once, untimed; another plain walk locates the
0-based target floor(0.9 × lines). Neither calls lineidx or scan_count. Default
manifest: 1,073,741,824 bytes, 8,947,842 lines, target 8,053,057. Every mapping
must preserve the validated size. Alternate paths receive TRACK labels and no
calibrated gates. The independent viewport oracle supports ASCII, tabs, controls
and CRLF; unsupported non-ASCII viewport fixtures fail correctness explicitly.
A substituted source returning no newlines leaves the oracle correct and its
exact-but-wrong index count fails validation. Wrong-size/count manifests fail.

`--self-check=16` (exit 1 → 0):
```text
SELF_CHECK 16 FAIL independent_oracle=0 rejects_tiny_fixture=0
SELF_CHECK 16 PASS independent_oracle=1 rejects_tiny_fixture=1
```

## §17 — accepted: enforceable, explicitly manual cold rows

Target A limits (G), p50/p99: G7 warm 80/125 ms, cold 600/800 ms;
G7j warm 30/50 ms, cold 250/350 ms. `--cold` skips warm-ups. AFTER the single
untimed oracle/open setup, each sample requires external `sync` + root-authorized
`drop_caches`, `fincore` verification and stdin `EVICTED`. The bench then checks
all pages nonresident via mincore without touching data, before its timed request.
No reference scan intervenes. Record block I/O/major faults externally for the
quiet verdict (perf §4). This bead never requested or performed root eviction.

Missing/expired acknowledgement or failed eviction returns 2; cold misses return
1. Warm-only gated success reports UNVALIDATED cold and returns 3. Cold-only
success reports warm unvalidated. TRACK never claims all gates met. Synthetic
checks exercise both percentile limits and reject a resident temporary fixture.

`--self-check=17`, untimed synthetic samples (exit 1 → 0):
```text
SELF_CHECK 17 FAIL cold_index_miss=0 cold_jump_miss=0 unvalidated_cold_fails=0
SELF_CHECK 17 PASS cold_index_miss=1 cold_jump_miss=1 unvalidated_cold_fails=1
```

## §18 — accepted: checked arguments and bounded waits

Checked decimal parsing rejects overflow, trailing text, empty/range errors and
unknown options. `--partial` is removed: only a fresh unbuilt workload is valid.
Reps accept 3–200; timeout-ms accepts 1–600000 (default 30000). Completion,
retirement, layout, stdin and test synchronization use monotonic deadlines.
Stopped-but-incomplete receives a final poll/recheck before rejection, since the
last publication can race the first poll. Diagnostics show prefix, complete,
building and deadline state. Failed waits exit 2 without a blocking destructor or
join, keeping sources alive until process termination. Mapping/submission errors
also fail. Barrier checks cover held workers, retirement and final publication.
