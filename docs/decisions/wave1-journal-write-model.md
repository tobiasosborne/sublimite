# W1 journal write model

## 1. Verdict and crash cuts

**1.1 (P) W1 falls as written.** Two outstanding checkpoints of the same buffer can have the same COMMIT bytes. At the T5 cut below, accepting the newer checkpoint can publish an unterminated group. Discarding it can discard the only committed, self-contained copy of the acknowledged text. The writer can stay on the UI thread. The smallest repair is to serialize checkpoint *producers for each buffer*, leaving ordinary commands on that buffer and checkpoints on other buffers free to interleave. If “per buffer” was intended to impose that restriction, it needs to be a writer **and reader** rule, including abandonment and restart. [W1(b–d)](../briefs/W1-journal-write-model.md) · [Checkpoint coverage and SAVE](../../src/journal/journal.h)

**1.2 (G) Crash model.** Start with a recoverable named journal. K sees the kernel-visible namespace and complete physical records. M sees a surviving valid prefix through the last successful barrier on that durably named inode. Later complete commands may survive. Before a changed frame or matching success reply a command may recover as absent or whole. After that publication K requires the whole command. M requires it once a barrier covers its final record. An incomplete record stops the physical scan. A missing group COMMIT discards only the logical operation. The evidence labels here distinguish contract gates (G) and deductions (P). Claim, trace, section and source numbers are identifiers. [K and M definitions](wave1-L2-q2-protocol.md#what-a-stop-means) · [Law 4](../../CLAUDE.md)

**1.3 (P) Two checkpoints on A, indistinguishable COMMIT.** Start with generation G containing arbitrary X followed by a delimiter. Choose X beyond the prefix witness and literal-inverse threshold, on a verified ORIGINAL that is still eligible for range restore. A deletes the delimiter, then deletes X as a separate undo group. Its published text is empty. The following journal records all reach the same inode.

| Claim | Interleaving |
|---|---|
| 1.3a (P) | BEGIN checkpoint C on A and write its empty descriptor. C needs only its final marker. Undo the deletion of X with an acknowledged standalone RESTORE_BASE_RANGE from G. A now contains X, dirty relative to the file with its delimiter. This is before save capture, so the operand is legal. |
| 1.3b (P) | BEGIN checkpoint D on A and write its descriptor and all its literal X slices. Both snapshots match their respective BEGIN boundaries. Emit **one** checkpoint COMMIT for A and sync through it. In history C the writer finalized C and left D unfinished. In history D it finalized D and left C unfinished. Both groups have supplied all required members for their own finalization, including exactly zero literals for the empty snapshot. Buffer, kind, global sequence and CRC on the final marker are identical in the two histories. |
| 1.3c (P) | Capture A for an ordinary save, permanently embargo G, sync the temp containing X, append and sync PREPARED, rename and sync the target parent. A foreign writer replaces the installed file and syncs the parent. **Kill or lose power here**, before another checkpoint completes. Both sources of the old/new replay are gone. The journal and namespace are identical across histories, including the bytes of the earlier undo and of D. |
| 1.3d (P) | In history D, **K and M must recover X** from the durable D and report the foreign binding. In history C, only empty C committed. Its suffix requires the missing G. **K and M must report unresolved BASE** and may offer available literal evidence. Installing D as complete in history C applies a partial group. Returning unresolved in history D loses the protection already purchased by its sync. Even perfect recognition of the foreign inode and full validation of the slice coverage cannot identify the COMMIT's owner. |

**1.4 (G) Minimal replacement used for the remaining cuts.** Give each buffer one command slot and one checkpoint slot, derived from the two group kinds. A BEGIN opens a fresh instance of its slot. A replacement BEGIN explicitly abandons the preceding uncommitted instance of that kind. A standalone text command is unambiguously complete and also supersedes an abandoned command on that buffer. A live command cannot be superseded until its owner aborts. A checkpoint request arriving behind a live checkpoint waits, coalesces only if its coverage and binding suffice, or cancels and restarts it. The UI rejects every stale worker member or completion by producer identity before append. On restart there are no surviving producers. A fresh BEGIN can thus retire an orphan even when its complete records remain in the file. An alternative allowing concurrent same-kind producers needs a group instance identifier on **every** member and marker, such as the image-local BEGIN sequence. [W1(b–c)](../briefs/W1-journal-write-model.md) · [Group shape](../../src/journal/journal.h)

Each cell includes the suffix surviving under 1.2. A complete eligible checkpoint can supply an independent origin. VIEW, TABS, other transactions and peer dirty identities have their own ordering. The following applies 1.4 and the existing A23 preconditions. **1.7 (P) Peer membership and generation policy are independent of writer ownership.** For T2/T3, fence new G-dependent admission through the target rename, including imports, reopen, kept drafts and changes to dependencies. Otherwise enumerate, protect and sync B, import another durable dirty draft on G, rename over G, then K: the missed draft loses its BASE in a controlled save. M gives the same wrong result after the target-parent barrier. Install VALUE_ONLY at capture for the **displaced** G across producers, including provisional commands already emitting a reference. Finish such a command before the relevant boundary, or abort and restage it by value. A reference emitted before the embargo but logically committed after the peer cutoff can defeat the checkpoint. An unavailable owner defers displacement. [T2–T4](wave1-L2-q2-protocol.md) · [Membership seam](wave1-savectl-spec.md#seam-table)

**1.8 (P) Edit kill cuts and failures.** BEFORE_BEGIN, AFTER_BEGIN, AFTER_DELETE, BEFORE_COMMIT, during a yielded replay, on abort, and just after successful RAM commit with the final record absent or torn: K recovers the previous whole command boundary. AFTER_COMMIT on the wire, before frame/ACK and after the matching external ACK: K recovers the whole new command. M uses the same old/whole rule at every cut and guarantees the new command after its final-record barrier. This applies to paste, replacement, undo and redo, including a singleton encoded and source-validated before RAM commit and appended after it. RAM-only cursor/history progress is invisible across a crash. A late mapped fault, overwrite, failed allocation or closing validation before RAM commit aborts the provisional edit. Preserve borrowed source provenance through the last load and check it. A precommit short write also leaves a physical tail requiring repair. After RAM commit the sole remaining record is already funded and encoded or infallibly frameable. Retain its exact bytes/offset on a short write, suspend further appends across the hole, keep the prior frame and withhold ACK until reconciled. No reread of a lost source or second RAM commit is needed. Aborting a command restores RAM claims, while physical sequence numbers of its successfully written members stay consumed. [Edit kill cuts, E1 and E3](wave1-edit-spec.md) · [Signed errata](wave0-plan-amendments.md#reopened-not-yet-amended-advisor-2026-11-24-joint-read-of-savectl-62c1441-and-edit-aa25e91)

**1.9 (P) Scheduling qualification.** “At least one ready record per turn” allows a scheduler to choose typing on every turn while a peer checkpoint waits forever. Provide fair service to ready producers and to barriers, bounded mailbox credit, and capacity for admitted operations to close. At fixed membership a finite checkpoint can then finish under continuous typing, assuming I/O and workers progress. There is no elapsed-time guarantee. A key can still wait behind its own provisional command, the global FIFO head under Q15, a physical append gap or a blocking pwrite. The provable isolation is that a healthy independent append need not wait for another buffer's entire checkpoint or command batch to own and release the journal. ## 2. Wire delta and reader cost

**2.1 (G) Landed fields.** The SJNL preamble contains magic, version, required features, generation and buffer allocator high-waters, and CRC32C. The SJR1 record header contains magic, total length, type, CRC32C, image-local sequence and buffer ID. Its size is 32 B (P, four 4 B fields plus two 8 B fields). Sequence advances globally on every non-PAD record, including records of abandoned groups. PAD has sequence and buffer ID zero. Buffer IDs are never reused. In the landed grammar BEGIN and COMMIT also have ID zero, empty payloads and no group discriminator. The checkpoint descriptor already carries covered sequence, current/saved content IDs, HAS_SAVED and text length. PREPARED already carries s, the saved ID, prior/new generation keys, destination expectation and the temp fd witness. CANCELLED can already name a checkpoint COMMIT. [Landed header §§1–8](../../src/journal/journal.h) · [2.1 wire decision](L2-2a-journal-wire.md)

**2.2 (P) Proposed encoding for 1.4.** Use distinct values in the existing type word for standalone, command member and checkpoint member where the opcode would be ambiguous, and for command/checkpoint BEGIN and COMMIT. Give every marker and member its nonzero owner buffer ID. A standalone INSERT, command INSERT and checkpoint INSERT must decode distinctly even after an abort or restart. Checkpoint TARGET also needs its role distinguished from independent TARGET. Retain session-level PAD, GENERATION and TABS. This encoding adds **zero header bytes per record** (P, type variants reuse the existing type word). The ordinary one-byte key remains 41 B (P, 32 B header + 8 B destination + 1 literal byte). Reject illegal type/role/owner combinations. Under 1.4 the BEGIN sequence identifies a slot instance while scanning. If same-buffer same-kind overlap is required instead, a u64 BEGIN reference costs 8 B per referencing record (P, width of the existing sequence space). Neither change is on the landed wire. Amend pre-freeze by advisor signature under the head note. [Record header and group rules](../../src/journal/journal.h) · [Reopened items](wave0-plan-amendments.md#reopened-not-yet-amended-advisor-2026-11-24-joint-read-of-savectl-62c1441-and-edit-aa25e91)

**2.3 (G) Boundaries and controls.** Pin a *published* snapshot, its content/saved IDs and its complete covered text boundary when BEGIN is accepted. A provisional tree is ineligible. The descriptor repeats that boundary; it does not sample a later tree. Accept checkpoint members in role order: descriptor, cumulative literal slices covering the exact length including empty text, optional trailing TARGET, final marker. A text command's logical position is its standalone record or its COMMIT, even if some members precede a selected cutoff. The covered text boundary and the visibility of optional metadata at COMMIT are separate. Guard adoption of a staged TARGET/saved association against a newer binding/save decision; defer, omit or restart a stale restatement. Keep independent VIEW and TABS updates. [Checkpoint descriptor](../../src/journal/journal.h) · [T2 replay](wave1-L2-q2-protocol.md#t2-save-as-over-a-dirty-peer--holds)

**2.4 (P) Append-only SAVE needs a change of meaning in the reader.** Plan PREPARED and matching terminal records by (buffer ID, token). Stage the installed fd's GENERATION declaration and any required binding consequences before FINISHED, activating the new origin and saver cutoff together at the terminal record. An orphan declaration can reserve a key but cannot bind a buffer, authorize a range on the new generation or mark anything saved. Derive Save As peer bindings from the selected transaction, or stage its dependent metadata with explicit ownership until that terminal. A freestanding unconditional peer TARGET changed before FINISHED is unsafe if only its prefix survives. Keep/conflict use the checkpoint's atomic TARGET where needed. CANCELLED refers to a complete matching checkpoint or the still-usable prior representation after namespace reconciliation. Resolve only its token. Terminal durability and any external completion require the appropriate barrier and verification. This replaces the finish-image requirement and “no RESTORE in this image may reference [the new key]” with eligibility after a verified, complete finish. Preserve an independently usable checkpoint on foreign binding, including after earlier finishes. Multiple successive saves require choosing the latest applicable origin before demanding superseded sources. [SAVE payloads](../../src/journal/journal.h) · [L2-3 prepare/finish/cancel](../briefs/L2-3-journal-save.md)

**2.5 (P) Two logical passes, with an explicit memory bill.** In pass one validate preamble, framing, CRC, global sequence and typed payloads up to the first physical failure. Track per-buffer command/checkpoint slots with BEGIN, owner, shape, coverage, optional TARGET and member offsets. On a terminal, index the complete operation by its final sequence; drop incomplete/superseded slots from the logical plan. Record declarations and policy at use, BASE/checkpoint candidates, save tokens, independent metadata and allocator high-waters. Select per-buffer old/new/conflict origins before opening a BASE. In pass two materialize the chosen origins from their indexed members, then visit complete suffix commands in final-sequence order, rereading their member offsets against the chosen origin. Apply a whole validated command under its buffer's piece checkpoint; abort on semantic failure and report the unresolved state. Checkpoint slices never enter the command replay. Walk metadata by its own effective positions. The data pass can seek on the pinned inode. This construction does not require a sequential re-scan of the entire suffix for every open group.

**2.6 (P) Cost of that construction.** For R physical records, B distinct buffers, D declared generations, T tokens and N journal bytes, slot state is at most 2B (P, one command and one checkpoint per buffer). The offset index is O(R) words, including the worst case of interleaved members and many acknowledged keys between BEGIN and COMMIT. Tables add O(B + D + T) entries plus retained path bytes or offsets to them. Use checked growth and one record window bounded by 1 MiB (G, landed maximum). Recovering from the immutable file needs O(N) journal-byte work and O(R) record visits/seeks per pass with direct indexed member lists, excluding source verification, actual output trees and their replay costs. The bound allows a constant number of reads per selected record. It makes no constant-RAM claim for the entire reader. Workers can supply bounded payload buffers and payload CRCs. Only the append owner knows the final global sequence after interleaving: finalize the header and CRC there, or combine a header CRC with the precomputed payload CRC. Preassigning a physical interval per producer can leave a hole before an ACK. [Wire CRC and sequence](../../src/journal/journal.h) · [Q6/Q7](wave1-L2-derivations.md)

**2.7 (P) Repair and barriers.** Report the last structurally valid *physical* offset and sequence independently of which groups committed. Keep whole orphan members on disk at EOF. Resume after them, discarding stale producer state. Truncate only a demonstrably torn final record. Preserve complete corruption with following bytes by setting the image aside intact. Never seek forward past corruption to apply a convenient later marker. Seal through at least the promised final, pin the named fd and image epoch, and credit only the submitted watermark after successful sync. Rotation must exclude in-flight old-inode durability promises and pinned save cutoffs from capture onward, including the pre-PREPARED temp phase. On an exact match the UI switches name and routes subsequent appends as one serialized action. Before parent sync M may see either image. Neither new durability credits nor dependent target renames can rely on the new name until that barrier succeeds. [Repair contract](../briefs/L2-2b-journal-runtime.md) · [Exact-match switch](wave1-L2-derivations.md#q7-amended-exclusive-grant-requirement)

**2.8 (P) Physical seal discrepancy for the wire owner.** The M traces above use the stipulated durable-prefix contract. The landed PAD formula aligns the *stream* offset. Its file offset is preamble + stream offset, hence a sealed end is 32 B into a 4,096 B file block (P, 32 B preamble + a multiple of the wire page). If a COMMIT ends at an already stream-aligned offset, its 32 B marker can occupy the beginning of the file block modified by the next append. A torn rewrite of that block is precisely the failure §4's PAD justification assumes. Align the absolute file end, or establish the durable-prefix premise independently for the storage model before claiming that PAD implements it. This is distinct from the indistinguishable histories, which already break under ideal barriers. [Wire §§1, 3 and 4](../../src/journal/journal.h)

## 5. Alternatives and decision boundary

**5.1 (P) Exclusive writer grant.** Take it for a peer checkpoint of L literal bytes in k slices. With the landed framing this occupies L + 40k + 132 B of the writer, plus any TARGET (P, literals, one header and destination per slice, BEGIN + descriptor + COMMIT). A ready one-byte key on another buffer waits for all remaining slices. A long command undo has the same problem. Releasing the grant per record under 2.1 instead lets an unrelated INSERT invalidate or enter the contiguous group. K between it and COMMIT can lose that ACK. [2.1 wire](../../src/journal/journal.h) · [Q7 amended](wave1-L2-derivations.md#q7-amended-exclusive-grant-requirement)

**5.2 (P) Private image for each save-side publication.** A synced candidate exactly matching the active image's logical watermark, policy and dependencies can switch safely, provided fd routing and directory durability follow 2.7. A single peer can require recoding the whole session. Admit one complete key after every private sync and before each comparison: every comparison misses, even though disk and UI both progress. Carrying the final tail in the switch also fails M if a synced edit on the old inode is copied only to new page cache, the rename survives and the copied bytes do not. Optional compaction can tolerate misses at quiescence; a controlled save that needs peer protection cannot depend on one.
