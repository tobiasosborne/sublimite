## Kernel and work bound

`src/find/literal.c` owns the literal kernel. `find_int.h` shares the reader and
work meter with the reference regex engine; `literal.h` exposes internal plans
and the forced Two-Way test mode. `find.c` keeps the reference Thompson NFA,
capture policy, compilation and enumeration semantics, using the literal kernel
only to find mandatory-prefix candidate starts.

The pair filter picks the lowest-ranked needle byte using a static text/code
frequency table, then the lowest-ranked byte with a different value. The first
selection keeps the earliest tie and the second keeps the latest tie. If every
byte is equal, the second position is the opposite end. This selects the `b` in
`a` x31 + `b`, and in needles whose first and last bytes are `a` with `b` in the
middle or at index 1. The table is immutable; there is no new mutable global.

SSE2 searches 32 starts with two pairs of 16-byte loads, comparisons, AND and
movemask. Runtime CPU dispatch enables AVX2 using a local target attribute;
it searches two 32-start blocks together and returns the earliest candidate
block. Full-needle `memcmp` verifies each candidate in chunks of at most 1024
bytes. Arbitrary bytes and non-overlapping enumeration follow the frozen API.

Let S be credited scanned starts, V the sum of full needle lengths charged for
verification, and n the needle length. After a failed verification, **V > 4S +
8n** switches the plan permanently to deterministic Two-Way, beginning at the
next unexamined start. The crossing verification can add at most n beyond the
threshold. Early `memcmp` failure still charges n, so the budget is conservative.
AVX2 lookahead is metered for cancellation but earns no credit when it will be
reexamined. Match returns can credit one extra 32-start block; the number of
non-overlapping matches is bounded by source length, and successful verification
lengths sum to at most source length. Verification plus scanning and the
Two-Way remainder therefore have deterministic O(source + needle) work.

Two-Way lazily computes both maximal suffixes, picks a critical factorisation,
and uses periodic memory where applicable. It has no shift table or allocation.
The variant tests assert that a weak pair filter actually trips the budget;
forced Two-Way results are also compared with an independent naive model.
Rabin-Karp alone and a first/last-byte-only filter remain rejected; a shift-table
Two-Way implementation adds unnecessary per-call table setup and stack space.

A one-byte needle uses a 64-byte counting loop, retaining only the first 4096
absolute offsets. Snapshots use direct spans where possible and a 4 KiB stack
window for straddling starts or small spans. Needles over 2048 bytes use Two-Way
through the lazy snapshot reader. Search, next and capture calls allocate no
memory; the frozen GCC find test passed its counting-allocator guard.

## Cancellation boundary and regression

The shared meter permits at most `FIND_POLL_UNITS` (1024) combined work units
between polls, including literal preprocessing, comparisons and candidate
advances. Pair scans reserve three units per start, at most 320 starts per call,
reduced by meter use. Every scanner call is charged independently; verification
can reset the meter between calls. AVX2 lookahead, failed comparisons, candidate
retirement, rank selection and bounded snapshot copies are all metered.

The last inherited boundary correction polls on `units + charge >= 1024`, leaves
headroom when combining literal and regex work, and charges Two-Way retirement
**before** returning a match or advancing a candidate. Returning before that
charge could miss cancellation pending at the boundary.

The earlier accounting and precancel tests did not cover that return. New
`two_way_cancel_boundaries()` prepares the real periodic/nonperiodic plans, then
seeds the meter and sets an atomic cancellation flag to exercise every work
boundary of a single candidate. It covers full matches, right-half misses and
left-half misses, as well as uncancelled searches just below and at a poll.
It uses no racing thread or timing assertion.
