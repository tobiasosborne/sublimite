## 1. BLOCKER — A forged SelectionClear destroys the clipboard

**Fix:** Reject synthetic SelectionClear events, or confirm actual ownership asynchronously before releasing data. Replace the current test with a forgery-rejection test and a genuine ownership-transfer test.

## 2. BLOCKER — Finite event bursts silently lose typed characters

Location: [src/x11/x11.c:365](/home/tobias/Projects/editor/src/x11/x11.c:365), [src/x11/input.c:211](/home/tobias/Projects/editor/src/x11/input.c:211).

`drain()` consumes every available raw X event before popping the 256-slot input ring. Dispatch ignores failed queue pushes.

**Repro:** Queue 129 alternating press/release pairs for a printable key before entering the loop. Translation produces 258 events; the last pair is dropped. One character disappears. **Fix:** Deliver queued events while consuming raw events, before capacity is exhausted. Preserve key transitions and clipboard completions; coalesce replaceable motion instead of discarding edits. Add a live burst test asserting exact character and completion counts.

## 3. BLOCKER — Direct callbacks overtake earlier queued input

Location: [src/x11/x11.c:263](/home/tobias/Projects/editor/src/x11/x11.c:263), [src/x11/x11.c:294](/home/tobias/Projects/editor/src/x11/x11.c:294).

**Repro:** Put `KeyPress(A), FocusOut` in the X queue. The consumer receives FocusOut first, then the earlier A press. Likewise, a close callback can save the document before previously received edits have reached the consumer.

**Fix:** Preserve arrival order across application callbacks. Deliver preceding input before invoking a direct callback, or use one ordered delivery mechanism. Test key-before-focus, key-before-close, and pointer-before-resize sequences.

## 13. MAJOR — Clipboard processing performs bulk work between input checks

Location: [src/x11/clip.c:236](/home/tobias/Projects/editor/src/x11/clip.c:236), [src/x11/clip.c:329](/home/tobias/Projects/editor/src/x11/clip.c:329), [src/x11/clip.c:438](/home/tobias/Projects/editor/src/x11/clip.c:438).

**Repro/argument:**
