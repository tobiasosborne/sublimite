- **MAJOR — Close can abandon a partially executed cut.** [src/editor/clip.c:647](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/clip.c:647), [src/editor/editor.c:1111](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:1111). Close flushes without running the continuation. Recovery can discard the unfinished journal group, making the cut reappear. **Fix:** hold close until replacement, selection repair, undo-group completion, and journal-group commit finish; propagate continuation errors.

- **MAJOR — Parked probes can falsely classify a healthy recovered tab as a paint crash.** [src/editor/editor.c:538](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:538), [src/editor/checkpoint.c:432](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/checkpoint.c:432). Leave a covered, never-successfully-presented recovered tab parked because native latency is unavailable. Each probe requests another actual submission and rearms `PAINT`. A process termination while that attempt waits causes recovery to restore the healthy tab closed. Unsuccessful cycles also append guard arm/clear records without edits. The report’s kill failure demonstrates this exposure; minimizing the fixture bypasses it. **Fix:** clear the guard after safe CPU composition and before an undrawn latency wait; rearm immediately around the actual native drawing attempt. Add a covered, non-minimized crash/recovery oracle.

- **MAJOR — An expose can leave an expired probe deadline spinning forever.** [src/editor/editor.c:798](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:798), [src/editor/editor.c:1000](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:1000). An expose queued before parking can wait behind a save/journal fence. If that fence clears before the scheduled probe, expose dispatch clears `win_unavailable` but leaves `win_retry_ns`. After successful presentation, that deadline remains; once expired, `wait_timeout` continually returns zero. Tobias gets sustained idle CPU consumption. **Fix:** clear the deadline whenever parking ends, route expose recovery through the common helper, and consider the deadline only while `win_unavailable`.
