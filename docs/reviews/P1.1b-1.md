Width matches `tables.h` for every code point, and the generated tables match their vendored UCD inputs.

1. **MAJOR — One grapheme call can exceed the UI slice budget.** [src/utf8/utf8.c:179](/home/tobias/Projects/editor/src/utf8/utf8.c:179), [bench/utf8_bench.c:106](/home/tobias/Projects/editor/bench/utf8_bench.c:106).  
   The loop consumes an arbitrarily long cluster without yielding. `a` followed by 24,576 U+0301 marks produces a 49,153-byte cluster; its median call took approximately **0.73 ms (M)[bat]**, already exceeding the **0.5 ms (G)** limit. Grapheme timings cannot fail the benchmark.  
   **Fix:** provide resumable segmentation with a bounded work budget and an explicit “incomplete” result. Preserve state across chunks; truncating `n` must not manufacture a cluster boundary. Gate long combining, Prepend, and ZWJ chains.

2. **MAJOR — The Control approximation breaks both GB4 and GB5.** [src/utf8/utf8.c:140](/home/tobias/Projects/editor/src/utf8/utf8.c:140), [docs/decisions/P1.1b.md:51](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:51).  
   **3,828** UCD GCB=Control code points become Other, including reserved characters—not just Cf. Reproductions:
   
   - U+200B U+0301: returns **5 bytes**, expected **3**.
   - U+0600 U+200B: returns **5 bytes**, expected **2**.
   
   The second case contradicts the decision’s claim that omitted controls still break from their predecessor: GB9b joins them after Prepend.  
   **Fix:** generate the actual Control property and classify it before applying joining rules; correct the decision’s description. [Unicode 15.1 grapheme rules](https://www.unicode.org/reports/tr29/tr29-43.html).

3. **MAJOR — GB9c splits Indic conjuncts.** [src/utf8/utf8.c:192](/home/tobias/Projects/editor/src/utf8/utf8.c:192), [src/utf8/utf8.h:98](/home/tobias/Projects/editor/src/utf8/utf8.h:98).  
   This is documented, but remains a significant editing deviation. U+0915 U+094D U+0915 returns **6 bytes**, whereas the extended cluster is **9 bytes**. Adding U+200D after the virama similarly returns 9 instead of 12.  
   **Fix:** generate InCB=Consonant/Extend/Linker from the already-vendored `DerivedCoreProperties.txt`; track consonant/linker state and implement GB9c before GB11. [Unicode 15.1 GB9c](https://www.unicode.org/reports/tr29/tr29-43.html).

4. **MAJOR — Grapheme validation lacks a semantic oracle.** [tests/utf8_test.c:262](/home/tobias/Projects/editor/tests/utf8_test.c:262), [fuzz/utf8_fuzz.c:83](/home/tobias/Projects/editor/fuzz/utf8_fuzz.c:83).  
   Hand-selected examples and “advances/tiles/lands on a unit boundary” checks do not establish correct segmentation. The fuzzer accepts many incorrect boundaries, including both deviations above.  
   **Fix:** vendor and execute every Unicode 15.1 `GraphemeBreakTest.txt` case, checking the complete boundary vector. Add an independent property-based segmentation oracle to fuzzing, with an explicit invalid-byte policy. Include Control×Extend, Prepend×Control, GB11 interruption cases, long RI runs, and Indic linker chains.

6. **MINOR — The replacement microgates are misattributed to the performance contract.** [docs/decisions/P1.1b.md:56](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:56), [bench/utf8_bench.c:1](/home/tobias/Projects/editor/bench/utf8_bench.c:1).

   **Fix:** identify them as local allocations, explain their derivation, and distinguish microgate success from verification of G1.

7. **MINOR — The gated workload is narrow and cache-warm.** [bench/utf8_bench.c:89](/home/tobias/Projects/editor/bench/utf8_bench.c:89), [bench/utf8_bench.c:123](/home/tobias/Projects/editor/bench/utf8_bench.c:123), [bench/utf8_bench.c:127](/home/tobias/Projects/editor/bench/utf8_bench.c:127).  
   Only synthetic script runs fail the decode gate; IID and grapheme workloads are informational. ASCII repeatedly scans one warmed 96 KiB allocation. Malformed bytes, combining-heavy text, and cold/after-idle behavior are absent.  
   **Fix:** add representative and adverse workload cases with explicit applicable budgets. Label ASCII results as cache-warm prefix scanning; use matched workloads when comparing implementations.

8. **MINOR — Attribution of a gate miss to preemption is unsupported.** [docs/decisions/P1.1b.md:73](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:73).  
   Loaded execution and a wall-clock spike do not establish that preemption caused the miss. Preemption also remains part of a wall-time budget.  
   **Fix:** preserve the complete acceptance record and substantiate causal attribution with scheduler traces; do not use it to waive a binding miss.

9. **MINOR — Truncated fuzz views lack matching ASan boundaries.** [fuzz/utf8_fuzz.c:64](/home/tobias/Projects/editor/fuzz/utf8_fuzz.c:64).  
   Passing `k` still leaves subsequent bytes inside the original allocation. An unnecessary read past `p[k-1]` can escape ASan if it does not alter the result. The exact-size unit tests mitigate this gap.  
   **Fix:** place each truncated prefix at the end of an allocation, as `place()` does, or poison the logical tail.

10. **MINOR — Byte-exact reconstruction of malformed input is not tested.** [fuzz/utf8_fuzz.c:58](/home/tobias/Projects/editor/fuzz/utf8_fuzz.c:58).  
    Only valid units are re-encoded. Blindly encoding an invalid unit’s `cp` changes its byte representation; blindly using scalar width makes an invalid byte `AD` zero-width.  
    **Fix:** test complete reconstruction using encode for valid units and the original byte for invalid units. Document that invalid placeholders need width 1 independently of scalar width.

11. **MINOR — Cached UCD inputs are trusted, and their checksums are overwritten.** [tools/ucdgen.py:18](/home/tobias/Projects/editor/tools/ucdgen.py:18), [tools/ucdgen.py:28](/home/tobias/Projects/editor/tools/ucdgen.py:28), [tests/utf8_tables_test.c:39](/home/tobias/Projects/editor/tests/utf8_tables_test.c:39).  
    Wrong-version or damaged cached inputs can be relabeled Unicode 15.1, with newly generated checksums blessing them. Sortedness checks and width comparisons against the same generated tables cannot detect this. Current inputs checked correctly.  
    **Fix:** verify immutable expected hashes and version metadata before generation; use versioned cache directories and add a non-mutating regeneration check to CI.

12. **MINOR — Width documentation overpromises width 1 for unassigned characters.** [src/utf8/utf8.h:87](/home/tobias/Projects/editor/src/utf8/utf8.h:87).  
    Unassigned U+2FFFD returns 2 because EAW=W; unassigned U+E01F0 returns 0 because Default_Ignorable. Both correctly follow the tables.  
    **Fix:** qualify the statement with the zero/wide precedence and add explicit examples.

13. **MINOR — The suggested cluster-width heuristic fails for Prepend.** [docs/decisions/P1.1b.md:81](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:81).  
    “Width of the first scalar” makes U+0600 plus a visible Arabic letter width 0. It also leaves keycap and presentation-sequence behavior underspecified.  
    **Fix:** define and test a cluster-width policy covering leading Prepend/marks, Hangul, emoji presentation, keycaps, modifiers, flags, and ZWJ sequences before implementing layout.

14. **MINOR — ASCII skipping is incorrectly described as uniform cell advancement.** [docs/decisions/P1.1b.md:47](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:47).  
    `utf8_ascii_run` includes tabs and line endings. Its result cannot generally mean “each byte is 1 cell.”  
    **Fix:** describe it as a decoding/validation shortcut; layout must separately handle tabs and line structure, or use a printable-ASCII helper.

15. **MINOR — Throughput percentile labels are reversed by reciprocation.** [bench/utf8_bench.c:131](/home/tobias/Projects/editor/bench/utf8_bench.c:131), [docs/decisions/P1.1b.md:69](/home/tobias/Projects/editor/docs/decisions/P1.1b.md:69).
