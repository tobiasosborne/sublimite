2. New defects introduced by round 4:

- **MAJOR — A paste behind an expired publication can make close hang indefinitely.** [editor.c:1345](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:1345), [clip.c:270](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/clip.c:270), [clip.c:382](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/clip.c:382). Start Ctrl+X while native publication is stuck, queue Ctrl+V, then close. Publication expires, but the accepted paste queues behind the same blocked native worker and sets `waiting`. Reads have no deadline. Clipboard busy prevents the close boundary from completing; admission rejects Escape and further commands, and repeated close cannot escape. Tobias sees an editor that neither accepts typing nor closes. A delayed-render paste alone can also stall this boundary for Windows’ [30-second rendering timeout](https://devblogs.microsoft.com/oldnewthing/20220609-00/?p=106731). **Fix:** identify and deadline clipboard reads too, invalidate late insertions after cancellation/expiry, and let close finish through the detached-worker lifetime.

- **MINOR — Queued typing can prevent the timeout notice from ever appearing.** [clip.c:610](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/clip.c:610), [session.c:747](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/session.c:747). Start Ctrl+C, type `q` while publication is pending, and let it expire. Expiry records the current mutation count; the resumed FIFO inserts `q` before composition. The overlay requires that count still match, so Tobias receives no timeout explanation. The same applies to cut expiry followed by queued editing. **Fix:** allow an unshown notice to appear in at least one status frame before applying its mutation-based lifetime.

3. Other first-hour gaps:

- **MINOR — Window close bypasses a close prompt’s Save As continuation.** [editor.c:1351](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/editor.c:1351), [input.c:1019](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/input.c:1019). Modify an untitled tab, press Ctrl+W, choose `S`, then click window close while entering the filename. Choosing Save clears the close-prompt owner and opens `go.active`; the boundary checks only `editor_close_prompt_shown`. It exits without completing Save As. Document text remains recoverable, but the filename entry disappears and no requested file is saved. **Fix:** preserve ownership through the Save As prompt, cancelling the window-close boundary and reopening admission while an answer is required.

- **MINOR — Reducing font size brings back the maximized blank strip.** [open.c:162](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/open.c:162), [font_size.c:200](/home/tobiasosborne/Projects/sublimite/.wt/edit-177r.9-s28/src/editor/font_size.c:200). At 96 DPI with the default embedded font, maximize on 5120 pixels, then reduce 10 pt to 9 pt. Startup reserves 640 columns using 8-pixel cells; the new 7-pixel cells remain capped at 640 columns, covering only 4480 pixels. Tobias sees a 640-pixel blank strip and prematurely constrained wrapping/chrome. Lower-DPI adoption can produce the same limitation. **Fix:** reserve for the smallest supported cell metrics, or enlarge grid reservations during font preparation before adopting smaller cells.
