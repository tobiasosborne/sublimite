# Exact strong imports from the release toolchain and its C library, per module.
#
# One grant per line: SYMBOL SCOPE # reason
#   SCOPE '*'     any module. Only for imports that neither enter the kernel
#                 nor touch process-global state; a '*' line is the symbol's
#                 only line.
#   SCOPE MODULE  that module only, one line per module granted. Everything
#                 that enters the kernel or touches process-global state:
#                 syscall wrappers, file, memory and heap calls, signals,
#                 processes, threads, clocks, environment, errno, stdio.
# MODULE must be in the layer map (mk/layers.mk) or be one of the implicit
# pseudo-modules main and vendor_ts (docs/decisions/v2-he7.24.md). Keep each block sorted;
# a module's grants form one block so parallel additions do not collide.
# Rationale and borderline cases: docs/decisions/v2-he7.22.md.
