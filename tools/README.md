# tools/ registry

**Rule: every file under `tools/` must have a row in this table** with its backticked path relative to `tools/`, purpose, invocation and make target. `make check-lints` fails for unregistered files and rows whose file is missing. The registry itself and generated `__pycache__/` directories are exempt.

| Tool | Purpose | Invocation | Make target |
|---|---|---|---|
| `check_dag.py` | Reads compiler `.d` files to enforce the layer and module orders in `docs/PLAN_V2.md` §2, including L5's ban on reaching x11, wayland, gl, and raster. | `python3 tools/check_dag.py` after compiling | `check-lints` |
| `check_no_c_includes.py` | Rejects tests and fuzzers whose compiler `.d` files list a C implementation file other than their own source. | `python3 tools/check_no_c_includes.py` after compiling | `check-lints` |
| `check_isolation.py` | Requires the literal `APP_ID := sublimite-v2` in the Makefile. Rejects hardcoded identity spellings and local `EDIT_APP_ID` redefinitions in C source. | `python3 tools/check_isolation.py` | `check-lints` |
| `clex.py` | Minimal C lexer for the source-level identity check. | Imported by `tools/check_isolation.py` | `check-lints` |
| `tests/isolation/run.py` | Checks the isolation lint against independent source and Makefile fixtures and verifies that Make rejects a v1 identity override. | `python3 -B tests/isolation/run.py` | `check-lints` |
| `tests/lanes/run.py` | Fixtures for the suite-lane table, lane guards, tools registry and lint inventory, each a mutated copy of the checkout under the build tree that must be rejected with its diagnostic. `--baseline` runs them against a tree without `check-layout`/`check-includes`. | `python3 tests/lanes/run.py --build-dir build` | `check-lints` |
| `tests/lint/run.py` | Compiles fixture translation units and verifies both dependency lints' verdicts. | `python3 tests/lint/run.py` | `check-lints` |
| `t3quota.py` | Quota and pace per provider (Claude, Codex, Gemini), read from T3 Code's caches (`~/.t3/caches/<provider>.json`, `usageLimits`). The coordinator runs it before each dispatch wave; ROOM is the points left before uniform pace. Muse and Pi report no data there. Its AGE column matters: a row older than your last dispatch on that provider does not include it; read the system `quota` tool instead. | `python3 tools/t3quota.py [--json]` | none (coordinator tool) |
| `check_symbols.py` | Audits release archive imports and exports against the module DAG, restricts each system import to the modules granted it, and validates per-module `LDLIBS`. | `make check-symbols`; `--system-symbols FILE` replaces the grant list (fixtures) | `check-lints`, `check-module-ldlibs` |
| `system-symbols.txt` | Exact, reviewed libc and toolchain imports, one `SYMBOL SCOPE # reason` grant per line: `*` for pure imports, otherwise the module granted it (only `os` may enter the kernel; see `docs/decisions/v2-he7.22.md`). | Read by `tools/check_symbols.py` | `check-lints` |
| `tests/contract/xdriver.c` and `xdriver.py` | Persistent XCB/XTest input, selection transfers and ordered inspection markers for the behavioral contract. | `build/xdriver --display :NUMBER` on the runner's authenticated display, or import `XDriver` from `tests/contract/xdriver.py`. | `xdriver`, `check-xdriver` |
| `tests/contract/cases/files.py` | Inspected v1 file contracts R3 (save with Find Results open) and R5 (binary open/reopen), on disk and in settled frames. | `make check-contract-files ORACLE_TREE=/absolute/inspected/v1/tree CONTRACT_DISPLAY=:160` | `check-contract-files` |
| `check_layout.py` | Validates the suite-lane table `tests/lanes.mk` (one sorted `<suite> := <lanes>` line per suite on disk, known lanes, make's derived lane lists equal to the table; `docs/decisions/v2-he7.26.md`), checks the tools registry and forbidden directories, and checks real test/fuzzer dependencies for C implementation includes. | `make check-layout` and `make check-includes` | `check-lints`, suite lanes |
| `tests/contract/cases/large_undo.py` and `large_undo_fixture.py` | X3: delete an over-cap file, undo, save; compares bytes on the stock v1 oracle, with deterministic twin/over fixtures. On the pin it reports the A8 failure signature; only the runner's manifest makes that an XFAIL. | `make check-contract-large-undo ORACLE=/absolute/oracle/build/sublimite CONTRACT_DISPLAY=:140` | `check-contract-large-undo` |
| `tests/contract/test_large_undo.py` | Self-test for X3: result classification and a stub editor whose failing control must report ERROR. | `python3 -B tests/contract/test_large_undo.py --display :140` | `check-contract` (via the runner), `check-contract-large-undo` |
| `tests/contract/run.py` | Contract runner: hashes the target, selects its reviewed binding in `tests/contract/expectations.json`, invokes each due case script once on a private display from its pool, reconciles the RECORD lines (`tests/contract/records.py`) and writes `gate.json` + `summary.txt`. | `python3 -B tests/contract/run.py --role harness --displays :120-:129`; `--validate` checks the manifest | `check-contract`, `contract-gate` |
| `tests/contract/records.py` | Shared result-record schema, exit statuses (PASS 0, FAIL 3, ERROR 4, runner-only XPASS 5) and the unittest adapter every contract case and self-test reports through. | Imported by the case scripts, self-tests and `tests/contract/run.py` | `check-contract`, `contract-gate` |
| `tests/contract/test_run.py` and `runner_fixture.py` | Runner self-test: missing/duplicate IDs, mislabelled or unproven XFAIL, XPASS, wrong role, missing display or script, timeout, malformed records and a fail-once fixture that must never rerun. | `python3 -B tests/contract/test_run.py` | `check-contract` |

`make check-lints` runs `tests/lint/run.py` for compiler-dependency fixtures and `tests/lanes/run.py` for suite, registry and lint inventory fixtures.
